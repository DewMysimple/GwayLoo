# ADR-001｜独立运行环境与主线隔离

## 状态

`active`

## 决策

`Dew-StanzaVerse` 使用自己的源码、依赖、配置、资产、验证产物、Git 仓库和 `wiki_memory/`。它可以拥有与 Verminoble 主线相同的资产，但运行时不得通过路径、依赖或配置引用主线工程。

## 理由

- 支持脱离主线主程序独立复刻和验证功能。
- 让支线可以独立提交、回退和演进，不把实验性变化带入主线。
- 让相同资产的存在不等于运行时耦合。

## 验证方式

- 检查应用资源路径、依赖配置和日志链接均指向本项目相对路径。
- 支线 Git 状态与主线仓库分开检查，主线不跟踪本项目内容。
