# 当前约束

## 项目与来源

- `app/` 是当前可运行应用；`sources/original-extraction/` 是只读原始基线，不能修改或写入生成物。
- `evidence/` 中的已接受证据不能覆盖；新证据使用新的日期或运行标识。
- 原始品牌、文案、媒体、字体和模型只用于本地研究与视觉验证，不发布、不部署、不接入远程商业服务。

## 生成物与验证

- 可再生产物只写入 `app/node_modules/`、`app/dist/` 或 `app/.artifacts/`，不纳入 Git。
- 资源、源码和 QA 变更必须优先使用本项目的本地路径，不引用 Verminoble 主线。
- 重要渲染或交互修复需要运行 TypeScript、构建、素材完整性和既定 QA 检查。

## Git

- 本项目使用独立 Git 仓库和远程，不作为 Verminoble 主仓库的普通目录或子模块。
- 不要将 `app/S.cmd`、依赖、构建产物或本地 QA 缓存作为本次记忆迁移的一部分提交。
