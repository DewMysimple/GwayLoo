# 系统架构

应用基于 Vite、TypeScript、Three r149 与 GSAP。`ExperienceState` 统一协调加载、滚动、诗歌、全屏绘画、内容与 Restart 状态。

主工程解构边界：`app/src/experience/definition.ts` 聚合 Branch 自有资源、六个场景、五个声音、26 个纸片、Ground atlas、reveal/camera timing 和运行时常量；`ExperienceManager` 将同一 definition 注入水彩世界、FluidSimulation 和 Full Paint，保留 source-extracted shader/config 作为底层事实来源。主工程当前 R3F 路径仍未应用全部 shader 输入，因此 Branch 不以 R3F 的浅层 MeshBasic 实现替换已完成的 WebGL 深度。

运行时状态边界：`app/src/experience/runtime/` 对应主工程 `src/features/experience/runtime/`，以纯 reducer 维护资产进度/就绪、boot/loading/exploring/landscape/tail/error、滚动派生的诗句与场景、静音、性能档位和错误信息；`ExperienceManager` 将资源事件、ScrollController、Full Paint 和 context loss 映射到该状态。reducer 只接受窄的 `RuntimeSelectionConfig`，不再保留硬编码 scene/poem 默认值；生产入口必须传入由 `ExperienceDefinition` 派生的 `RuntimeContract`，避免旧时间线静默接管。Branch 的 `ExperienceState.phase` 仍表示 legacy WebGL/GSAP 视觉转场，不能与主工程 runtime phase 混为同一字段。

运行时输入与契约边界：`runtime/input.ts` 负责不依赖 DOM 的滚动时间线映射、wheel/touch 归一化和 progress clamp；`runtime/selection.ts` 负责诗句断点与六场景选择；`runtime/contract.ts` 从 `ExperienceDefinition` 派生 scene starts、poem breakpoints、camera tail 和 travel multiplier；`runtime/audio.ts` 只把 main/poem/landscape 语义映射到既有 AudioManager 主题名。根目录主工程的 React `useExperienceAudio` 未直接迁入，因为 Branch 已有 DOM 音频生命周期；该边界保持单一播放器。

内容状态边界：`app/src/content/` 镜像主工程的 copy、fonts、tail 契约，`ContentDefinitionAdapter` 在 DOM 交互和 TextCanvas 测量之前应用加载文案、两份诗句 DOM、尾部权益、FAQ 和静态 token。Loader、TextCanvas、AudioManager、PaintingTitles 和 WatercolorView 消费同一 definition；适配层只更新 Branch 自有 DOM，不连接主工程路径或远程商业服务。

资源状态边界：`app/src/content/world.ts` 镜像主工程 `worldAssets` 的本地路径和资源注册关系，输出 `staticResources`、视频资源生成器与设备判定；`ExperienceDefinition.assets.device/videoResources` 在资源预载和运行时初始化边界解析同一设备能力，`ExperienceDefinition.world.assets` 同时被入口的 KTX2 transcoder setup 消费。Branch 的 papers/Ground layout/reveal timing 仍保留在 world 同级，作为 legacy WebGL 参数层，后续再逐项合并 source-derived metadata。

设备与降级边界：`Cursor`、`GrassLayer`、`LeavesLayer`、`ScrollCamera`、`TextCanvas`、`UIView`、`PaintManager` 与 `FullPaintManager` 不再直接读取 `config/assets.ts` 或各自重算移动端条件；`WatercolorView` 在 init 时按 Definition device 构造设备敏感层，移动端关闭完整草/树叶 pass、使用 0.6 秒长按和移动视频资源，桌面使用 0.3 秒长按与完整 vegetation。`config/assets.ts` 暂保留为历史事实映射，没有 runtime import。停笔 activity 还必须有最近真实指针输入或主动按压，避免平滑尾帧无限刷新流体 grace。

2D 文字输入边界：主滚动 `UIView` 对应源码 `Q5` 的 UI-plane raycast 生命周期，cursor distortion 初始在 `(1000,1000)` 屏外，只有进入 `.xp-text-sizer` 对应平面才更新 target；首次命中立即定位，之后以 `damping=6` 按帧平滑，移出平面不再被全局 DOM 坐标持续改写，Restart 会清除 target。主滚动文字采用源码 `visibleArea=0.95` 与 `uFadeNoiseSize=0.25`；Poem TextMesh 保持自己的 `visibleArea=1.25`、`uFadeNoiseSize=0.07`、`uCursorFactor=0`，两层不共用交互参数。

场景内容边界：`ExperienceDefinition.scenes` 现在承接主工程 `src/content/scenes.ts` 的六组 label、title 和 `focusProgress`；`focusTime` 只是由该进度乘以 baked camera duration 得到的兼容值，`ExperienceManager` 再把同一进度注入 runtime reducer 的 `sceneStarts`。因此场景标题、点击目标和滚动派生共享一份定义，避免从 `PAPERS_CONFIG` 的纸片标题/`startAt` 反向猜测场景内容。

图集与资源边界：`app/src/content/atlas.ts` 承接主工程 atlas 内容模块的 source-derived SDF/纹理 remap 和 26 个 layer schedule；`WatercolorView` 只消费 `definition.world.atlas`，不直接 import JSON。`world.ts` 的 `staticResources` 与 `worldAssets` 一一对应，包含主工程已注册的 `rgbaNoise`，避免路径存在但 loader 图遗漏。`PAPERS_CONFIG` 的 ground/sdf/leaves/cutout 参数暂作为 legacy WebGL 输入保留，后续按职责逐项迁移。

纸片 manifest 边界：`app/src/content/papers.ts` 是 `config/papers.ts` 原始提取数据与运行时之间的唯一 content adapter；`ExperienceDefinition.world.papers` 向 WatercolorView 注入 26 项 paper manifest，Paper shader、PaintingTitles、LeavesLayer、Ground、Shadow/Cutout 和 reveal timing 不再各自读取 config。原始 config 暂保留为只读事实来源，后续可进一步拆成 ground/SDF/vegetation/shadow 子契约。

Paper 子职责边界：`app/src/content/paper-layers.ts` 从只读 `paperManifest` 派生 `world.paperLayers` 的四组窄契约。`ground` 只描述 Ground atlas/开关，`sdf` 只描述 SDF、reveal 类型与透明度，`vegetation` 只描述树叶/hover，`shadow` 只描述 castShadow 与 cutout hole；每组都携带 26 项的 index/name/startAt/sceneIndex 对齐身份。LeavesLayer 只消费 vegetation，WatercolorView 的 Ground、SDF/reveal、shadow/cutout 路径只消费相应契约；完整 `world.papers` 仍由中央编排、标题和兼容逻辑使用。根目录主工程目前没有可直接复制的同等 Paper WebGL 实现，因此这里是基于源码 manifest 的解构适配，而不是对不存在的主工程 `paper.ts` 做猜测性迁移。

Paper 场景呈现边界：`world.paperLayers.presentation` 在同一只读 manifest 上提供标题层和场景主纸选择所需的最小字段。`PaintingTitles` 只消费该契约来匹配 GLB `titles` 代理、生成 CTA 和 interaction bounds；`FluidSimulation.regionRemap(sceneIndex)` 与 `splatScene(sceneIndex)` 也只从该契约选择带 title 的主纸，再映射到局部/Full Paint simulation region。这样 `world.papers` 不再成为标题和 scene→simulation 选择的隐式全局依赖，同时不改变现有 26+1 tile、标题数量或水彩参数。

Paper identity/reveal 边界：`PaperIdentityContract` 从 presentation 契约中抽出 `index/name/startAt/sceneIndex`，作为 WatercolorView 的 GLB 查找、simulation region、射线 sceneIndex、Ground 关联和实例调试身份。`PaperEntry`、`PaperInstanceConfig` 不再携带完整 `PaperConfig`；普通显现入口读取 identity.startAt，fade/default 分支读取 `PaperSdfContract.revealType`，Ground 尺寸/深度继续读取 `PaperGroundContract`。Paper runtime 另外保留 source-derived `revealDelay`：按相同 `startAt` 的 TZ 组计算首纸 1.5 秒入口 delay 与组内 0.3 秒错峰，`startAt` 只负责建立动画，Paper/Cutout/Ground 共享该延迟时间线；`?noIntro` 只跳过首纸入口 delay。GLB 加入场景后先 `updateMatrixWorld(true)`，`PaperEntry` 保存 proxy 的 world position/scale/quaternion，实例位置和 yaw 取该 authoring transform；可见实例仍按源码 geometry-derived `meshSize` 构建，不直接把 worldScale 乘进可见纸片。Restart 时 Paper/Cutout/Shadow/Ground 共享 0.5 秒 `sine.inOut` hide timeline，隐藏期间 `_isHiding` 禁止重复 reveal，完成回调后才清空 `revealed`、Ground visible 和 GPU alpha；确定性 QA 可用 `hideAll({ immediate: true })`。完整 `world.papers` 只保留在 content definition 与兼容 QA/中央事实层，不再作为 Paper runtime 实例的隐式总线。

- 相机：真实内容高度驱动的 `7.5×` 滚动行程（用户定制偏离原站）；按源码恢复 `container → PerspectiveCamera` 层级，`Camera_Action_Baked` 以 59.7667 秒 translation/rotation 轨道驱动 parent container，入口按源码 5 秒 `sine.out` 执行，指针只在 child camera 局部 rotation 上按 NDC `2.55°/9.2°` 两轴和 `0.3` 指数阻尼工作，不再旋转 baked world position；移动端/reduced-motion 禁止视差。Branch 交付层将有效 NDC 限制为 `±0.2`，以保持窄视场下的可交付构图；真实中心→边缘探针确认相机 world position 不漂移。原始滚动触发纸片，受限阻尼滚动驱动相机，最大滞后为总进度 1.5%。桌面 100px 滚动约推进 0.36 秒镜头。
- 纸片：26 个 GLB 节点只作变换和射线代理；可见纸面使用共享的 10×10 细分实例平面、纹理图集与 SDF 边缘。实例矩阵读取纸片 GLB 节点的世界四元数 yaw，保留 `tree_1`、`viaduc_1` 等节点自身朝向，使可见纸面、射线代理、地面和阴影保持同向。所有层初始倒伏，按 `startAt` 并行触发可切换的 reveal profile；同一源码 TZ 组的 Paper/Cutout/Ground 共享 source-derived delay，首纸 1.5 秒、组内每项再错峰 0.3 秒，delay 不改变滚动触发阈值。默认 delivery 为 3 秒立起、5 秒曲面舒展和 7 秒 `uRevealProgress: 0→15` 水彩生成；`?reveal=source` 恢复源码 7 秒 `back.out` 立起、10 秒 `quart.out` 曲面舒展和 15 秒线性显色。普通纸片在 delivery profile 保留源码四点 reveal 前沿与从归一化进度 0.18 开始的二次 edge catch-up，并在第 6.5 秒锁定完成；source profile 将该 Branch 补全层置零，避免像素差分混入额外底图。`revealType: fade` 的透明背景层保持平面与完成曲面，只执行源码 3 秒 alpha 淡入，不进入普通纸片的立起曲线。
- Full Paint：使用第 27 个独立模拟区域；tile 按源码横竖屏规则保持桌面宽 1024/移动竖屏高 512，再按 viewport ratio 求另一轴；全屏纸片保留源码 `uScale: 1.4→1` 的进入轨道、`uVisibleProgress: 0→3.8` 的 reveal，并以 `computeInkReveal` 的 global intensity 作为真实 alpha。`isVisible` 在 progress 超过 0.8 后才成立，退出未穿过该阈值前继续抑制普通 tile；fragment 保留源码直接输出 `inkColor` 的颜色契约。视频 base 失败才退出，over 失败回退到 base 并继续保留渲染/交互；完成退出后才释放视频纹理，resize 会重算 Full Paint 的 reveal 点。
- 水彩：每张纸按纸片与地面真实尺寸获得独立动态模拟区域；命中使用 GLB 真实形状代理和最近可见层规则。纸片坐标保留源码的两阶段 X 转换（射线命中时翻转、进入 `paperBox` 前翻回），地面使用独立的 Y 转换，避免纸片笔触左右镜像。`BrushSample` 同时携带前后中心、前后半径、标准化 NDC 速度和源码尺度；hover 按源码把速度 `[0, 0.08]` 映射到尺度 `[0.2, 1.8]`，external-force 正式路径使用源码 v2 椭圆 SDF，并把半径投影为纸片/ground tile 的横纵半径以保持屏幕圆度，切换纸片时清除连续性。流体按源码执行 external force → advection → divergence → pressure → gradient subtract → accumulation；advection 恢复源码 active v2 的多步 backtrace/forward-trace 链，并把每次采样夹在当前 atlas region 内。Divergence 使用单格邻域并按实例 `dt` 归一化，基础 `dt=0.008` 再按 `tileWidth / atlasWidth` 缩放，`mouseForce=50`、`deceleration=0.98`、`attenuation=0.96` 与 `intensity=0.06` 分开维护，并将逐帧系数换算为实际帧时长；七个 HalfFloat simulation target 保留 stencil buffer，独立 stencil mesh 依据 `aStencilActive` 裁剪 atlas tile，`wasActive`→`wasActive4` 四帧历史负责离开后的冲刷，hidden→visible 时强制两帧全量同步；普通 pass 只清 stencil、不擦除其他纸片颜色。普通纸片命中刷新 5 秒 activity grace，但只有最近真实指针输入或主动按压才允许平滑尾帧继续注入，Full Paint 可见时只激活第 27 个 tile，离开/重启会清理当前 active 与历史状态；旧位置约 3 秒平滑衰减。dry/ink LUT 令未交互区域低对比、交互区域显色，并由速度方向产生折射式 UV 扰动；不再使用持久颜料补偿。
- 地面与草：源码 Ground 使用覆盖 26 个纸片索引的单个 `SourceGroundsBatch` InstancedMesh，实例属性携带各自尺寸、simulationBox、simulationRemap 和 Ground 变换，材质按 `uVisible[]`、`uAlpha[]`、`uAtlasRemap[]` 控制每个实例；Ground alpha 按源码从 0 以 0.4 秒淡入，射线通过 `instanceId` 回写纸片索引，GrassLayer 只接收 Ground 变换元数据。屏幕材质 resize 使用 renderer drawing-buffer 分辨率。桌面草叶按源码固定密度 Poisson（1.8–2.8、7 次尝试）、椭圆簇、10 片图集、24 段渐变及 Perlin 风动生成，并为每个 patch 恢复覆盖完整草地的 bounding box/sphere，避免滚动时被基础 blade 几何错误剔除；命中约 1 秒升起、约 3 秒回落，移动端不启用完整草实例。树叶由全局 `LeavesLayer` 管理 1024 个实例和 32×32 position pass；`PaintManager` 只把源码 `paintIntersection` 的纸片命中、`uv2.x > 0` 边界和移动速度交给它，Ground 命中保持独立，不会误注入树叶。源码叶片顶点展开、五片图集和三态 fog 在同一层完成。
- 全局 Ground：在 per-paper Ground 之外恢复源码独立的 `SourceGlobalGroundLayer`；从 GLB `Ground` 复制 world position/scale/quaternion，创建 `2000×2000` 平面，绕 X 轴 `-PI/2`，设为 `renderOrder=-3`、`receiveShadow=true`，并用 `globalGround` shader 消费投影阴影、`uShadowStrength=0.9`、共享 Lighting/Background、noise、fog 和 drawing-buffer resolution。全屏 Background 由独立 `background.ts` 恢复原始 27/28 shader 形状，复用 Paper 的 `uBackground/uLighting` descriptor 并保持 `uRatio`/主相机逆矩阵 adapter；Background 仍只负责背景/高光/fog，ShadowProjection 仍只生成投影纹理且不消费 `uShadowMap`，Cutouts 仍独立消费带孔纸片 SDF 阴影；最终五视口 QA 已验证这组结构与 uniform 契约。
- Fluid 每实例邻域：原始 Divergence/Pressure/Gradient 的顶点输入以 `px[INSTANCE_COUNT]` 表达每张纸自己的 simulation cell size。Branch 现在用实例属性 `aCellScale=(1/tile.width, 1/tile.height)` 传入 `vCellScale`，三类 fragment pass 均用它取左右/上下邻居并夹在各自 atlas region 内，不再共享整张 atlas 的 `uTexelSize`；`SimulationRegion.texelSize` 也明确表示该 tile 的 atlas-normalized 单格。这样保留了 per-tile `dt=0.008×tileWidth/atlasWidth` 的时间步长契约，并修正不同纸片分辨率下的空间邻域契约。完整性、build、TypeScript 和五视口运行时 QA 已通过；视觉基线仍须固定 seed/freeze/reveal 后与主工程做差分。
- 阴影：24 个 `castShadow` 图层经 5×5 投影纸片、SDF 图集、源码方向光、spread/attenuation/skew 参数写入屏幕 RenderTarget；独立 `CutoutShadowLayer` 再以 24 个 `hasHole` 纸片的 SDF atlas、切线空间深度偏移和 `uShadowMap` 消费该投影，按源码把 cutout shadow 与 paper shadow 分开混合并用 0.4 秒 alpha 生命周期控制显示。Ground、Paper 等其他消费层读取同一投影，全屏 Background 只负责源码的渐变、屏幕高光和三态 fog，不重复扣除 shadow；RenderTarget 与所有 `gl_FragCoord` 材质共享物理绘制分辨率，Background 的 fog depth/world position 共享主相机逆矩阵契约。
- 标题：从 GLB `titles` 节点读取六个场景标签，用本地 Canela MSDF 字体渲染，并可进入对应 Full Paint。
- 诗歌：使用独立 UI 正交相机；Poem Background 消费第 27 个 Full Screen simulation tile 与 watercolor paper texture，按源码 `uSimulationAlpha` 4 秒显现/3.5 秒收拢；Poem TextMesh 复用 `TextCanvas` 内的原始 `hK`（400×2304）和 `poem/texture` 四瓦片布局，采样前三个 sharp/low/high UV，并保留 `uTileRatio`、`uTextRatio`、`uSharpUvs` 等源码映射；主滚动页仍独立使用 DOM 三瓦片 Canvas，避免两种文字窗口互相改变。`writeFadeIn` 由 `uWriteProgress: 0.7→0` 驱动，`customFadeOut` 期间保持场景渲染直到完成。
- 音频：`AudioManager` 以 Enter 点击作为解锁入口，统一维护静音偏好、页面可见性及 `loop-main`、`loop-poem`、`loop-painting` 主题；主题音量 1，交叉淡入淡出 0.8 秒；sound toggle 的 aria label 从 definition 的 soundOn/soundOff 读取。
- 光标：桌面端保留原站 95px 双 SVG 指示器；`.out-circle` 是无断线的完整圆环，`.in-circle` 是中心点，画纸悬停切换为白色圆形笔刷态，移动端/平板隐藏；QA 检查圆环尺寸、断线属性、SVG overflow 和中心点。
- 尾部：恢复主工程 tailCopy 的本地静态权益、offer、5 条 FAQ、分享/奖项文案和 Restart；Substack 保留 4 段、gift/email/awards token 渲染为静态 span，不接入远程购买、账户或分享服务，资源失败时仍保留文字内容。
- 降级：Advantages 的 FAQ、Restart 和静态权益绑定先于 WebGL runtime 初始化；reduced-motion、renderer 创建失败、资源/运行时异常或 WebGL context loss 时，fallback 仍保留 FAQ 可读性与 Restart 回顶路径。context loss 会停止 `WebGLApp` ticker、静音音频、阻止 boot/resize 继续提交，并要求重新加载以重建 Three/FBO 资源图。
