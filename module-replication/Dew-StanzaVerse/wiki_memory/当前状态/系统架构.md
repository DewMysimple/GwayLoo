# 系统架构

应用基于 Vite、TypeScript、Three r149 与 GSAP。`ExperienceState` 统一协调加载、滚动、诗歌、全屏绘画、内容与 Restart 状态。

- 相机：真实内容高度驱动的 `7.5×` 滚动行程（用户定制偏离原站）；`Camera_Action_Baked` 以 59.7667 秒 translation/rotation 轨道驱动，入口按源码 5 秒 `sine.out` 执行，指针按 NDC `2.55°/9.2°` 两轴和 `0.3` 指数阻尼在 world-space 作用于相机位置与朝向，移动端/reduced-motion 禁止视差；原始滚动触发纸片，受限阻尼滚动驱动相机，最大滞后为总进度 1.5%。桌面 100px 滚动约推进 0.36 秒镜头。
- 纸片：26 个 GLB 节点只作变换和射线代理；可见纸面使用共享的 10×10 细分实例平面、纹理图集与 SDF 边缘。实例矩阵读取纸片 GLB 节点的世界四元数 yaw，保留 `tree_1`、`viaduc_1` 等节点自身朝向，使可见纸面、射线代理、地面和阴影保持同向。所有层初始倒伏，按 `startAt` 并行触发可切换的 reveal profile：默认 delivery 为 3 秒立起、5 秒曲面舒展和 7 秒 `uRevealProgress: 0→15` 水彩生成；`?reveal=source` 恢复源码 7 秒 `back.out` 立起、10 秒 `quart.out` 曲面舒展和 15 秒线性显色。普通纸片在 delivery profile 保留源码四点 reveal 前沿与从归一化进度 0.18 开始的二次 edge catch-up，并在第 6.5 秒锁定完成；source profile 将该 Branch 补全层置零，避免像素差分混入额外底图。`revealType: fade` 的透明背景层保持平面与完成曲面，只执行源码 3 秒 alpha 淡入，不进入普通纸片的立起曲线。
- Full Paint：使用第 27 个独立模拟区域；tile 按源码横竖屏规则保持桌面宽 1024/移动竖屏高 512，再按 viewport ratio 求另一轴；全屏纸片保留源码 `uScale: 1.4→1` 的进入轨道、`uVisibleProgress: 0→3.8` 的 reveal，并以 `computeInkReveal` 的 global intensity 作为真实 alpha。`isVisible` 在 progress 超过 0.8 后才成立，退出未穿过该阈值前继续抑制普通 tile；fragment 保留源码直接输出 `inkColor` 的颜色契约。视频 base 失败才退出，over 失败回退到 base 并继续保留渲染/交互；完成退出后才释放视频纹理，resize 会重算 Full Paint 的 reveal 点。
- 水彩：每张纸按纸片与地面真实尺寸获得独立动态模拟区域；命中使用 GLB 真实形状代理和最近可见层规则。纸片坐标保留源码的两阶段 X 转换（射线命中时翻转、进入 `paperBox` 前翻回），地面使用独立的 Y 转换，避免纸片笔触左右镜像。`BrushSample` 同时携带前后中心、前后半径、标准化 NDC 速度和源码尺度；hover 按源码把速度 `[0, 0.08]` 映射到尺度 `[0.2, 1.8]`，external-force 正式路径使用源码 v2 椭圆 SDF，并把半径投影为纸片/ground tile 的横纵半径以保持屏幕圆度，切换纸片时清除连续性。流体按源码执行 external force → advection → divergence → pressure → gradient subtract → accumulation；advection 恢复源码 active v2 的多步 backtrace/forward-trace 链，并把每次采样夹在当前 atlas region 内。Divergence 使用单格邻域并按实例 `dt` 归一化，基础 `dt=0.008` 再按 `tileWidth / atlasWidth` 缩放，`mouseForce=50`、`deceleration=0.98`、`attenuation=0.96` 与 `intensity=0.06` 分开维护，并将逐帧系数换算为实际帧时长；七个 HalfFloat simulation target 保留 stencil buffer，独立 stencil mesh 依据 `aStencilActive` 裁剪 atlas tile，`wasActive`→`wasActive4` 四帧历史负责离开后的冲刷，hidden→visible 时强制两帧全量同步；普通 pass 只清 stencil、不擦除其他纸片颜色。普通纸片命中刷新 5 秒 activity grace，Full Paint 可见时只激活第 27 个 tile，离开/重启会清理当前 active 与历史状态；旧位置约 3 秒平滑衰减。dry/ink LUT 令未交互区域低对比、交互区域显色，并由速度方向产生折射式 UV 扰动；不再使用持久颜料补偿。
- 地面与草：源码 Ground 使用覆盖 26 个纸片索引的单个 `SourceGroundsBatch` InstancedMesh，实例属性携带各自尺寸、simulationBox、simulationRemap 和 Ground 变换，材质按 `uVisible[]`、`uAlpha[]`、`uAtlasRemap[]` 控制每个实例；Ground alpha 按源码从 0 以 0.4 秒淡入，射线通过 `instanceId` 回写纸片索引，GrassLayer 只接收 Ground 变换元数据。屏幕材质 resize 使用 renderer drawing-buffer 分辨率。桌面草叶按源码固定密度 Poisson（1.8–2.8、7 次尝试）、椭圆簇、10 片图集、24 段渐变及 Perlin 风动生成，并为每个 patch 恢复覆盖完整草地的 bounding box/sphere，避免滚动时被基础 blade 几何错误剔除；命中约 1 秒升起、约 3 秒回落，移动端不启用完整草实例。树叶由全局 `LeavesLayer` 管理 1024 个实例和 32×32 position pass；`PaintManager` 只把源码 `paintIntersection` 的纸片命中、`uv2.x > 0` 边界和移动速度交给它，Ground 命中保持独立，不会误注入树叶。源码叶片顶点展开、五片图集和三态 fog 在同一层完成。
- 全局 Ground：在 per-paper Ground 之外恢复源码独立的 `SourceGlobalGroundLayer`；从 GLB `Ground` 复制 world position/scale/quaternion，创建 `2000×2000` 平面，绕 X 轴 `-PI/2`，设为 `renderOrder=-3`、`receiveShadow=true`，并用 `globalGround` shader 消费投影阴影、`uShadowStrength=0.9`、共享 Lighting/Background、noise、fog 和 drawing-buffer resolution。全屏 Background 仍只负责背景/高光/fog 合成，ShadowProjection 仍只生成投影纹理，Cutouts 仍独立消费带孔纸片 SDF 阴影；最终五视口 QA 已验证这组结构与 uniform 契约。
- 阴影：24 个 `castShadow` 图层经 5×5 投影纸片、SDF 图集、源码方向光、spread/attenuation/skew 参数写入屏幕 RenderTarget；独立 `CutoutShadowLayer` 再以 24 个 `hasHole` 纸片的 SDF atlas、切线空间深度偏移和 `uShadowMap` 消费该投影，按源码把 cutout shadow 与 paper shadow 分开混合并用 0.4 秒 alpha 生命周期控制显示。Ground、Paper 等其他消费层读取同一投影，全屏 Background 只负责源码的渐变、屏幕高光和三态 fog，不重复扣除 shadow；RenderTarget 与所有 `gl_FragCoord` 材质共享物理绘制分辨率，Background 的 fog depth/world position 共享主相机逆矩阵契约。
- 标题：从 GLB `titles` 节点读取六个场景标签，用本地 Canela MSDF 字体渲染，并可进入对应 Full Paint。
- 诗歌：使用独立 UI 正交相机；Poem Background 消费第 27 个 Full Screen simulation tile 与 watercolor paper texture，按源码 `uSimulationAlpha` 4 秒显现/3.5 秒收拢；Poem TextMesh 复用 `TextCanvas` 内的原始 `hK`（400×2304）和 `poem/texture` 四瓦片布局，采样前三个 sharp/low/high UV，并保留 `uTileRatio`、`uTextRatio`、`uSharpUvs` 等源码映射；主滚动页仍独立使用 DOM 三瓦片 Canvas，避免两种文字窗口互相改变。`writeFadeIn` 由 `uWriteProgress: 0.7→0` 驱动，`customFadeOut` 期间保持场景渲染直到完成。
- 音频：`AudioManager` 以 Enter 点击作为解锁入口，统一维护静音偏好、页面可见性及 `loop-main`、`loop-poem`、`loop-painting` 主题；主题音量 1，交叉淡入淡出 0.8 秒。
- 光标：桌面端保留原站 95px 双 SVG 指示器；`.out-circle` 是无断线的完整圆环，`.in-circle` 是中心点，画纸悬停切换为白色圆形笔刷态，移动端/平板隐藏；QA 检查圆环尺寸、断线属性、SVG overflow 和中心点。
- 尾部：恢复本地静态权益、offer、FAQ、分享/奖项文案和 Restart；不接入远程购买、账户或分享服务，资源失败时仍保留文字内容。
- 降级：Advantages 的 FAQ、Restart 和静态权益绑定先于 WebGL runtime 初始化；reduced-motion、renderer 创建失败、资源/运行时异常或 WebGL context loss 时，fallback 仍保留 FAQ 可读性与 Restart 回顶路径。context loss 会停止 `WebGLApp` ticker、静音音频、阻止 boot/resize 继续提交，并要求重新加载以重建 Three/FBO 资源图。

代码入口集中在 `app/src/experience/`、`app/src/shaders/` 与 `app/src/config/`。验收约束见 [[知识/流程/验收基线|验收基线]]。
