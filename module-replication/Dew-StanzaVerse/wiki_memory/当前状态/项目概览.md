# 项目概览

David Whyte Experience 是一个仅本地使用的高保真水彩体验页重建工程。它不发布、不部署、不接入账户、购买、预约或远程商业服务。

## 入口

- 应用：`../../app/`
- 原始基线：`../../sources/original-extraction/`（只读）
- 当前验收证据：`../../evidence/qa/accepted-2026-08-20/`

## 常用命令

```powershell
Set-Location .\app
npm ci
npm run dev
npm run verify
npm run qa
```

完整性检查默认验证 73 个本地素材与内部原始镜像的一致性。参见
[[知识/规范/来源与完整性|来源与完整性]]、[[知识/流程/验收基线|验收基线]]。
