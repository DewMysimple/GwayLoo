# 项目概览

David Whyte Experience 是一个仅本地使用的高保真水彩体验页重建工程。它不发布、不部署、不接入账户、购买、预约或远程商业服务。

## 已确认的长期目标

继续以 Branch 的独立工程为复刻推演主线，优先提高水彩 WebGL 底层重建深度：纸片材质、流体笔触、reveal 时间线、Ground、草、阴影、相机、射线和 Full Paint 都要逐项接近可观测行为；同时持续提高当前可交付页面的加载、诗句、音频、响应式、reduced-motion、尾部内容、FAQ、Restart 和资源降级兼容性。

底层视觉还原与页面交付兼容性是并行目标。Branch 的推演实现不直接等同于主项目真实架构，后续仍保持 Branch 自己的源码、资产、依赖、证据和记忆边界。

## 入口

- 应用：`../../app/`
- 原始基线：`../../sources/original-extraction/`（只读）
- 当前验收证据：`../../evidence/qa/accepted-2026-08-20/`

```powershell
Set-Location .\app
npm ci
npm run dev
npm run verify
npm run qa
```
