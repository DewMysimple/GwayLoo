# Ground 与渲染分辨率契约对齐

## 目标

继续对照原始 Branch 提取源码，修复 Ground 显现生命周期和高 DPI/resize 下的屏幕空间坐标契约，覆盖纸片、地面、草、阴影、标题、诗歌和 Full Paint 的材质分辨率。

## 源码证据

- 原始 `Ground` 类把每个实例的 `uAlpha` 初始化为 0，在 `show()` 中以 0.4 秒 `sine.inOut` 从 0 淡入；当前实现原先只在 `hideAll()` 后设为 0，首次 reveal 会直接弹入。
- 原始 `onWindowResize` 接收布局尺寸与 `renderWidth/renderHeight` 两套值；Ground、纸片、草、标题、诗歌和 Full Paint 的屏幕 shader 使用后者，阴影 RenderTarget 也使用绘制缓冲区尺寸。
- Ground 的几何仍按源码使用 `ground.edges/depth`，纸片/地面独立 simulation box、地面 Y 翻转和纸片 X 两阶段转换保持不变。

## 本轮修改

- `app/src/experience/world/WatercolorView.ts`：Ground `uAlpha` 从 `baseAlpha`（当前为 0）启动，并用 `fromTo(0→1, 0.4s)` 对齐源码；resize 同步纸片和每张 Ground 的物理分辨率。
- `app/src/experience/world/ShadowProjection.ts`：resize 改为直接接受 renderer drawing-buffer 尺寸，避免 DPR 被重复乘算。
- `app/src/experience/WebGLApp.ts`、`app/src/main.ts`：renderer `setSize` 后读取 drawing buffer，并在初始化完成后执行一次 resize handshake。
- `GrassLayer`、`PaintingTitles`、`PoemView`、`FullPaintManager`：屏幕材质使用物理分辨率；标题另保留 CSS 逻辑分辨率用于命中框和布局。
- `app/scripts/qa-experience.mjs`：增加 Ground 初始 alpha/可见性/淡入时长与 canvas/纸片/Ground 分辨率一致性断言。
