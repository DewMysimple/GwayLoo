# 2026-08-24｜工程记忆架构迁移

## 目标

将 `Dew-StanzaVerse` 原 `工程记忆/` 迁移为与 Verminoble 主线同构的 `wiki_memory/`，保留既有历史并明确支线项目的独立记忆边界。

## 已确认的决策

- 记忆根目录使用 `wiki_memory/`，目录分为当前状态、决策、知识、日志、模板和工具。
- 既有主题内容提炼到当前状态、决策和知识页；既有分类日志改为统一日期标题日志，不删除历史事实。
- 本项目的工程记忆只服务于本独立 Git 仓库，不写入 Verminoble 主线 `wiki_memory/`。

## 检查与操作

- 检查原 `工程记忆/` 的主题页、分类日志、MOC 和维护协议。
- 将项目概览、架构与渲染、来源与完整性、目录与保留策略、验收基线迁移到新结构。
- 为十篇既有历史日志补充统一 YAML 元数据、日期标题和新路径链接。
- 增加当前约束、当前待办、已知问题、独立运行环境决策和统一日志说明。
- 更新项目根 `AGENTS.md` 与 `README.md`，使后续 Agent 只读取本地 `wiki_memory/`。

## 文件变更

- 原 `工程记忆/` 目录迁移为 `wiki_memory/`。
