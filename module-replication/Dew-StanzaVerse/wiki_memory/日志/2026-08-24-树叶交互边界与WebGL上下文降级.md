# 树叶交互边界与 WebGL 上下文降级

## 背景

本轮继续在 Branch `Dew-StanzaVerse` 内推进，不修改根目录主工程。树叶全局粒子层已经恢复，但对照源码后发现它的交互输入不是任意射线命中：源码 `paintIntersection` 只保留纸片命中，Ground 使用独立的 `groundIntersection`；树叶注入还要求命中 UV 的 `uv2.x > 0`。同时，页面已有资源失败和初始化失败 fallback，但 WebGL context loss 仍可能留下继续运行的 ticker、延迟 boot 或失去可读提示的空白场景。

## 本轮变更

- `PaintManager` 只把 `kind === "paper"` 的命中交给 `WatercolorView.setPaintInfosIntersection`；Ground、标题、诗句、Full Paint、无命中和交互关闭都会清除树叶交点，恢复源码的 paper-only 交互边界。
- `LeavesLayer` 在注入队列和颜色更新前过滤 `uvX <= 0`，并让 tint 持续向当前纸片的 source color 渐变；这样 Ground 命中不会错误地产生树叶，纸片边界也不会创建源码过滤掉的叶片。
- `main.ts` 监听 `webglcontextlost` / `webglcontextrestored`。上下文丢失时阻止默认行为、停止 `WebGLApp` ticker、解绑运行时、静音音频并进入可读 fallback；上下文恢复不尝试原地复用已失效的 Three/FBO 资源，而是保持 fallback 并要求重新加载。
- boot 在上下文或资源/初始化失败后不再继续构建体验；失效状态下 resize 也不再向失效 renderer 或场景模块发请求。

## 验证

- `npm exec -- tsc --noEmit`：通过。
- `node --check scripts/qa-experience.mjs`：通过。
- `qa-experience.mjs` 已加入合成 `webglcontextlost/restored` 的事件链检查，覆盖 `preventDefault`、运行时解绑、静音与 fallback；它只验证应用处理器，不等同于真实 GPU 驱动丢失。
- `git diff --check`：通过；输出只有现有的 LF/CRLF 转换提示。
- `npm run verify`：通过，Vite 54 modules，构建产物约 833.72 kB；`verify:integrity` 检查 73 个本地资源，`passed: true`、无 failures。仍有既有的单 bundle 大于 500 kB 警告。
- `npm run qa` / `npm run smoke`：当前环境没有监听 `127.0.0.1:9333` 的 CDP 页面目标，无法取得 context loss 事件、树叶 shader 实编译、真实命中注入和五视口像素证据；不能把本轮称为浏览器视觉验收完成。
