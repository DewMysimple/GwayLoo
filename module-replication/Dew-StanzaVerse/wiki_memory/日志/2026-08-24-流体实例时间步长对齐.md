# 流体实例时间步长对齐

## 目标

继续追踪水彩 WebGL 的实例级模拟契约，确认基础 `dt` 不只是全局常量，而是要随每张 tile 在共享 atlas 中的宽度缩放，避免不同分辨率纸片的速度场使用错误时间尺度。

## 源码证据

- 原始 `BatchInkSimulation` 的实例 getter 返回 `dt = authoredDt * (size.x / totalSize.x)`；hover 与 mousedown 的 authored `dt` 都是 `0.008`。
- 原始 `cellScale` 使用共享 FBO 的 `1 / totalSize`，而 `fboSize` 也指向共享 total size；因此 Branch 的 atlas 全局 texel size 与每实例 `dt` 缩放是两个不同契约，不能用固定 `0.008` 替代后者。
- Divergence 用每实例 `vDt` 做归一化，gradient 又用同一 `vDt` 把 pressure 梯度扣回速度；错误的实例 dt 会同时改变 pressure 和 advection 的时间尺度。

## 本轮修改

- `app/src/experience/paint/FluidSimulation.ts`：引入源码基础 `0.008`，初始化和每次 splat 都按 `state.fboSize.x / atlasSize` 计算实例 dt；Full Paint 第 27 个固定分辨率 tile 同样遵循该契约。
- `app/scripts/qa-experience.mjs`：增加所有 simulation state 的 `dt` 与 `0.008 × tileWidth / atlasWidth` 一致性断言，并保留 Divergence 单格采样与 `/vDt` 断言。
- `wiki_memory/当前状态/系统架构.md` 与 `当前待办.md`：将流体时间步长记录为基础值乘 tile/atlas 宽度比，并标记仍需 CDP 确认不同分辨率下的视觉结果。

## 验证

- `npm exec -- tsc --noEmit`：通过。
- `node --check scripts/qa-experience.mjs`：通过。
- `git diff --check`：通过；仅有 Git 的 LF/CRLF 提示。
- `npm run verify`：通过；Vite 构建成功，`assetCount=73`、`failures=[]`。
- 尚无有效 DevTools CDP 端点，因此 tile 间 advection、pressure、低速笔触和 Full Paint 的实际像素/截图证据仍未完成。

## 下一步

CDP 恢复后，在同一指针轨迹下比较小 tile、普通纸片 tile 与第 27 个 Full Paint tile 的 pigment、wetness 和旧位置衰减；随后继续审计 paper/ground shader 的 `uResolution` 与 atlas remap 是否还存在相同的实例/全局混用。
