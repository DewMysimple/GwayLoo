# 流体实例活跃生命周期对齐

## 目标

恢复原始 `BatchInkSimulation` 的实例活跃语义，区分“本帧是否命中/涂抹”“离开后延迟保活”和“Full Paint 覆盖态”，避免一次笔触把普通 tile 永久锁在模拟链中，也避免 Full Paint 切换时继续推进 26 张纸片。

## 源码证据

- 原始普通纸片的 `active` 是 `_overDelayed && paper.isInFrustum && !fullPaintManager.isVisible`；指针离开后通过 5 秒延迟把 `_overDelayed` 置为 false。
- 原始 Full Screen instance 在 Full Paint 或 Poem 视图 active；它不是某一张纸片的复用状态。
- 每帧 pass 使用当前 `active` 写入 `wasActive` uniform，完整 pass 链结束后才把 `wasActive = active` 推进到历史字段；Branch 此前在第一次 `splat` 后永久写 `state.wasActive = true`，且 shader 实际读取了这个锁存值。

## 本轮修改

- `app/src/experience/paint/FluidSimulation.ts`：增加每实例 5 秒 activity grace、当前帧 active 标记和 Full Paint 独立 active 切换；pass attribute 读取当前 `state.active`，`wasActive` 只保留为历史观察值；reset 会清理所有 activity 计时器。
- `app/src/experience/paint/PaintManager.ts`：每帧命中纸片/地面即刷新对应实例 active；Full Paint 可见时只激活第 27 个实例，即使指针静止或在 canvas 外也保持 overlay 模拟链有效。
- `app/scripts/qa-experience.mjs`：新增 active 标记、5 秒 grace 失活、Full Paint active 和普通实例抑制断言。

## 验证

- `npm exec -- tsc --noEmit`：通过。
- `node --check scripts/qa-experience.mjs`：通过。
- `git diff --check`：通过；仅有 Git 的 LF/CRLF 提示。
- `npm run verify`：通过；53 模块构建成功，`assetCount=73`、`failures=[]`。
- 当前没有有效 DevTools CDP，因此 5 秒离开 grace、纸片失活后的实际像素清理、Full Paint 视觉过渡仍未取得截图证据。

## 下一步

CDP 恢复后，依次验证：纸片 hover 停止后的约 3 秒湿度衰减、离开后的 5 秒 activity grace、进入 Full Paint 时普通纸片不再更新、退出后第 27 个 tile 不残留，以及 Restart 后所有 tile 的 active/wasActive 均归零。
