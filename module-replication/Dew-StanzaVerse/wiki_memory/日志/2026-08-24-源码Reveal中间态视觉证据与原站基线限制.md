# 源码 Reveal 中间态视觉证据与原站基线限制

## 目标

继续 Branch 的水彩 WebGL 底层复刻，确认上一轮建立的 `delivery` / `source` Reveal 双时序不是只在对象结构上成立，并为后续纸张底纹、墨迹前沿、相机和阴影的截图差分固定一个可重复中间态。

## 对照结论

- 使用同一 `seed=47`、`freeze=6`、1440×900 视口，在 Branch 内分别截取 delivery 与 source。source 中间态固定为 timeline `1.5s`、`uRevealProgress=1.5`、`completeLayerBaseline=0`；画面中的早期斜向纸张网纹会在相同 Reveal 进度下消退，确认它来自原始纸张底纹在未着墨阶段的可见性，不是应被抹平的 Branch 伪影。
- 远程原站 `/experience/` 只读试载停在品牌加载画面，并抛出 `hcaptcha is not defined`。当前环境不能把该远程画面作为可靠像素基线；后续视觉比较继续以本地 `sources/original-extraction/` 的 shader、资产哈希、bundle 参数和 Branch 固定截图为依据，不修改远程站点内容。

## 实现

- `app/scripts/qa-experience.mjs` 在五视口 delivery 回归后，额外加载 `?reveal=source`，固定重播第一张纸的 1.5 秒中间态，记录 `revealProgress`、`rotationZ`、`alpha`、`curve` 与 `completeLayerBaseline`，并输出 `source-profile-1440x900-mid.png`。
- 该截图只写入 `app/.artifacts/qa/`，没有进入只读 `sources/` 或正式 `evidence/qa/`。正式证据迁移仍等待视觉验收，不把候选截图冒充最终基线。

## 验证

- `node --check scripts/qa-experience.mjs`：通过。
- `npm run qa -- http://127.0.0.1:3000/ .artifacts/qa/source-visual-evidence-clean-2026-08-24`：通过；5 个视口、`sourceRevealProfilePassed=true`、`sourceRevealVisual.revealProgress=1.5`、`consoleErrors=[]`、`remoteResources=[]`。
- 输出：`app/.artifacts/qa/source-visual-evidence-clean-2026-08-24/source-profile-1440x900-mid.png` 与 `report.json`。

## 结果与遗留

Branch 现在有可复看的源码 Reveal 视觉中间态证据，后续可以把同一帧用于 shader、纸片材质和相机共同投影的差分。原站实时页面仍受第三方 hCaptcha 初始化影响，不能替代本地原始提取；下一步优先做本地资产基线与 Branch 的 Full Paint、Ground、shadow 边界差分。
