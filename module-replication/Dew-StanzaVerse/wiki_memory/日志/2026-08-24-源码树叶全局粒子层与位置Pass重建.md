# 源码树叶全局粒子层与位置 Pass 重建

## 背景

源码的树叶不是每张纸各自创建少量 `Points` 并做正弦漂移，而是 `F3` 全局层：固定 1024 个实例、32×32 position pass、命中画面时循环写入实例矩阵，并把 speed / angle / lifetime 写入状态纹理。Branch 原实现为每张带 `leaves` 配置的纸片创建 30 个点，既没有 position pass，也没有鼠标命中注入，因此只能形成装饰性漂移，无法还原源码的交互式叶片生命周期。

## 本轮变更

- 新增 `app/src/experience/world/LeavesLayer.ts`，恢复全局 1024-instance 叶片层、32×32 双 RenderTarget ping-pong、base state DataTexture、0.02 秒粒子队列和命中点实例矩阵。
- `app/src/shaders/world.ts` 的树叶顶点/片元着色器改为源码的 `aIndices`、随机缩放/旋转、position pass 读取、寿命投影、五片图集采样与 fog 合成路径；新增 position pass shader。
- `WatercolorView` 不再按纸片调用旧的 30 点 `_createLeaves`，改为创建一个全局 `LeavesLayer`，并在 renderer 主帧前推进 position pass；resize、Restart、fog 状态和调试状态均有独立入口。
- `PaintManager` 将当前射线命中、平滑 NDC 速度和移动状态转交树叶层；进入标题、诗句、Full Paint、无命中、交互关闭或指针离开时清除交点，避免叶片注入残留在错误上下文。
- 移动端保留源码式不启用完整叶片粒子层的降级；桌面才分配 1024 实例和 position pass 资源。
- `app/scripts/qa-experience.mjs` 增加 `leavesState` / `leavesLifecycle` 观测，桌面验收要求 `enabled=true`、`count=1024`、`passSize=32`、双 position pass 存在，并要求实际指针移动后循环索引被注入。

## 验证

- `npm exec -- tsc --noEmit`：通过。
- `node scripts/qa-experience.mjs` 语法检查：通过。
- `git diff --check`：通过；输出只有现有 CRLF 转换提示。
- `npm run verify`：通过，Vite 54 modules，assetCount 73，`passed: true`；构建仍有既有的单 bundle 大于 500 kB 警告。
- 当前环境没有监听 `127.0.0.1:9333` 的浏览器 CDP，因此尚未取得树叶 shader 实际编译、命中注入、DPR/横竖屏和快速移动下的像素证据；不能把本轮称为视觉验收完成。
