# Background 合成与阴影职责对齐

## 目标

继续把 Branch 的水彩底层按原始提取源码拆成可核对的职责边界，重点处理全屏 Background、ShadowProjection、Ground/Paper 材质之间的屏幕空间与 fog 合成关系。

## 源码证据

- 原始 Background `u5` 使用 `uBackground` 的 `#b4b4b4/#e4e4e4`、`progressRemap=(0.5,1)` 和 `uLighting` 的屏幕高光参数；它只负责背景渐变、屏幕高光和三态 fog，不直接读取 shadow map。
- 原始 Background 顶点用主相机 `uProjectionInverse/uViewMatrixInv` 从 far clip 重建 `vWorldPosition`，同时按背景平面在主相机 view 中的 z 计算 `vFogDepth`。
- 原始 ShadowProjection 的 RenderTarget 只提供投影阴影纹理；Ground、Paper 等材质在各自片元阶段读取它。把 shadow 再扣到全屏 Background 会造成职责重复和背景过暗。

## 本轮修改

- `app/src/experience/world/WatercolorView.ts`：Paper 的合并背景材质继续使用源码精确的 `uLighting/uBackground` 值。
- `app/src/experience/world/ShadowProjection.ts`：全屏合成恢复为 Background 的渐变 + 屏幕高光 + fog，不再重复扣除 shadow map；改用 `gl_FragCoord/uResolution` 和物理绘制分辨率，并加入主相机 view 矩阵以还原 Background 的 fog depth。
- `app/src/experience/WebGLApp.ts` 与 `app/src/experience/types.ts`：每帧将主相机、时间和 `opaque/occulted` fog 状态传入 Background 合成。
- `ShadowProjection.reset()`：重启时同步清空 GPU `aAlpha` attribute，避免只清 CPU 状态导致首帧残留投影。
- `app/scripts/qa-experience.mjs`：增加 Background noise、三套相机矩阵、fog 状态、物理分辨率和“不存在全屏 shadow uniform”的结构断言，并保留 Paper 源材质参数断言。

## 验证

- `npm exec -- tsc --noEmit`：通过。
- `node --check scripts/qa-experience.mjs`：通过。
- `npm run verify`：通过；Vite 构建成功，完整性 `assetCount=73`、`failures=[]`。
- 当前可探测的 9012、9013、10000 端口仍不是 DevTools CDP 端点，因此本轮没有把 shader 编译、fog 中间态、横竖屏视觉和阴影亮度宣称为已完成的运行时验收。

CDP 恢复后，优先在 1440×900、390×844 和 DPR>1 条件下截取基础态、Occulted fog、Opaque 转场和 Ground/Paper 显影中间态，确认 Background 不重复变暗、fog depth 不漂移、阴影仍只出现在 Ground/Paper 消费层。
