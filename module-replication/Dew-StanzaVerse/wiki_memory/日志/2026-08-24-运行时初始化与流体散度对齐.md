# 运行时初始化与流体散度对齐

## 目标

继续以 Branch 的原始提取源码为准，修复会影响可交付降级和水彩压力链量级的两个边界：初始化阶段异常必须进入可读 fallback，Divergence pass 必须恢复源码的单格差分与 `dt` 归一化。

## 源码证据

- 原始流体 Divergence 使用 `vPx` 的单像素邻域，计算 `(x1 - x0 + y1 - y0) / 2`，随后除以每个模拟实例的 `vDt`；此前支线使用两格邻域且没有 `/dt`，会改变 pressure/gradient 链的量级。
- 原始页面的 KTX2 转码器和 DOM 组件初始化属于首屏运行时边界。若这些调用在 `boot()` 的异常捕获之外抛错，WebGL 已创建但页面不会进入可读降级，资源或浏览器兼容性失败会表现为无响应空页。

## 本轮修改

- `app/src/shaders/fluid.ts`：Divergence 改为单 `uTexelSize` 邻域，差分乘 `0.5` 后除以 `max(vDt, 0.000001)`。
- `app/src/main.ts`：新增 `initializeRuntime()`，把 renderer 配置、KTX2、loader、cursor、Advantages、debug、audio、scroll 初始化包进异常边界；失败时释放 renderer 并调用现有 fallback。
- `app/scripts/qa-experience.mjs`：增加 Divergence 结构断言，并将流体 pass 状态纳入五视口验收报告。
