- 时间：2026-08-25（北京时间）
- 类型：`feature`
- 状态：`完成`

- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 源码证据与决策

- 原始 `Paper._createContainer()` 从 loaded mesh 提取 `getWorldPosition`、`getWorldScale`、`getWorldQuaternion`，再建立隐藏的 Paper container；Paper 可见实例随后按 container position / rotation 与 `meshSize` 建矩阵。
- 因此本轮没有把 GLB `worldScale` 误乘到可见实例：原始可见 Paper 的 `meshSize` 仍由几何 bounding box 的 `z/y` 尺寸提供。worldScale 作为独立 authoring transform 保存，供后续 Shadow/Ground/共同投影审计使用。
- Branch 原先用 `mesh.position + mesh.parent.position` 近似世界位置；当前 scene 的多数父级虽暂未造成明显偏差，但该写法无法覆盖更深层级的旋转、缩放和非平移父节点，不能作为源码等价实现。

## 本轮改动

- `app/src/experience/world/WatercolorView.ts`
  - 在把 GLB 加入场景后调用 `gltf.scene.updateMatrixWorld(true)`，确保提取前父级矩阵已解析。
  - `PaperEntry` 保存 `sourceWorldPosition`、`sourceWorldScale`、`sourceWorldQuaternion` 三项源码 authoring transform。
  - 可见 Paper proxy 的实例位置改为 `mesh.getWorldPosition()`；朝向继续从同一 world quaternion 推导 yaw，不改变现有 meshSize 轴映射和动态 reveal rotationZ。
- `app/scripts/qa-experience.mjs`
  - 新增 `paperWorldPositionAlignment`，断言每张纸的可见实例位置与 GLB proxy world position 最大误差小于 `1e-4`。
  - 新增 `sourceWorldScaleFinite`，确保每张 Paper 都保留有效的世界缩放证据。
