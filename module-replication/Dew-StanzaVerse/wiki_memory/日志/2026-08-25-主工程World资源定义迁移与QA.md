# 主工程 World 资源定义迁移与五视口 QA

## 目标

继续把根目录主工程 content/world 的资源契约解构到 Branch，消除模型、纹理、LUT、Poem/MSDF、Basis transcoder 和资源清单由不同 config/loader 各自拼接的架构差距。保持 Branch 本地资源 URL、现有 shader 参数和已验证 WebGL 行为不变。

## 已实施变更

- 新增 app/src/content/world.ts，建立 Branch 本地 worldAssets，覆盖 scene GLB、paper/atlas/noise/grass/leaves/Poem/MSDF、LUT、Ground KTX2、Basis transcoder 和相机资源元数据。
- 同一模块导出 staticResources 与 createVideoResources；experienceDefinition 不再从 config/assets.ts 读取资源清单，设备判断也进入 world definition 边界。
- experienceDefinition.world 增加 assets 子契约，保留 Branch 原有 papers、Ground atlas layout、reveal 和 camera timing 字段，避免改变已有 WebGL 模块接口。
- Resources.setupKtx2 接受 definition 提供的 transcoder path，main.ts 使用 world.assets.basisTranscoderPath，资源加载链不再硬编码 Basis 目录。
- QA 增加 world model、Ground atlas、resource binding 和 Basis path 断言；config/assets.ts 暂保留为历史来源文件，但不再是当前 definition 的运行时入口。

## 验证

- npx tsc --noEmit：通过。
- npm run build：通过；66 modules，JS 约 868 KB，仅保留已有大 chunk 警告。
- npm run verify:integrity：73/73 通过。
- node --check scripts/qa-experience.mjs：通过。
- 复用 Chrome 9333 唯一页面执行五视口 QA：passed: true、sourceRevealProfilePassed: true、5 cases、console errors 0、remote resources 0。
- QA 断言确认 world model 为 /xp/models/scene.glb、Ground atlas 为 /xp/textures/grounds/atlas.ktx2、静态资源项与 definition.world.assets 绑定、Basis path 为 /xp/libs/basis/。
- 纸片 reveal、流体笔触、Ground batch、Cutouts SDF 阴影、Full Paint、Poem、音频、context loss、reduced-motion、FAQ、Restart 和 cursor 门禁继续通过。
- Chrome 最终盘点：9333 只有一个页面，9334/9336/9337 均关闭；未创建重复页面。

## 遗留与下一步

- config/assets.ts 仍作为未删除的历史配置文件存在；后续应继续审计其他模块是否直接读取其中的路径，并逐项迁移到 definition，而不是一次性删除。
- Branch 的 world definition 仍保留 legacy papers/Ground timing 与主工程 worldAssets 的并行局部结构；下一轮可继续将 scene/paper 的可观测 metadata 归并到单一 source-derived manifest。
- 主工程与 Branch 尚未完成同 seed、同 viewport、同时间点的像素差分；本轮证明的是资源架构绑定和 Branch 自身运行行为。
