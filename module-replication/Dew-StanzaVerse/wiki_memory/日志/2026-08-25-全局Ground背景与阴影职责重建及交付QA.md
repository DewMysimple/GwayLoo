# 全局 Ground、Background 与阴影职责重建及交付 QA

## 背景

上一阶段已完成 `Cutouts` 独立 SDF 阴影层，记录见 [[日志/2026-08-25-Cutouts独立SDF阴影层重建与浏览器QA|Cutouts 独立 SDF 阴影层重建与浏览器 QA]]。本轮没有重复实现 Cutouts，而是继续审计源码中更上游的 `Ground`、`Background` 与 `ShadowProjection` 职责，修正 Branch 之前只有 per-paper Ground 和 fullscreen composite、缺少源码全局 Ground plane 的架构缺口。

## 源码证据与职责结论

原始源码的全局 `Ground` 不是每张纸附属的简化地面，也不是 Background 的替代物：

- 从 GLB `Ground` 节点取 world position、world scale、world quaternion，再移除原始 mesh。
- 重建 `2000×2000` PlaneGeometry，绕 X 轴 `-PI/2`，`renderOrder=-3`，`receiveShadow=true`。
- `Ground` 使用自己的材质和 fragment 路径，消费 `uShadowMap` 与 `uShadowStrength=0.9`，并共享 `uLighting`、`uBackground`、噪声纹理、fog 和 drawing-buffer resolution。
- Ground shader 在 `computeBackground` 的基础上扣除投影阴影，并保留天空高光、地面高光、world-position/fog depth 与 sRGB 输出。
- `Background` 仍是全屏合成层；`ShadowProjection` 负责生成投影纹理；局部 per-paper Ground、Cutouts 和全局 Ground 是不同消费者，不能合并成一个“背景减阴影”近似职责。

因此本轮的结论是：Branch 仍然保持独立复刻架构，但它现在恢复了源码可观测的全局 Ground 层级和资源责任，不把 Branch 误宣称为源码原始类图的逐字复制。

## Branch 改动

- 新增 `app/src/shaders/globalGround.ts`：重建全局 Ground 的 world-position、地面/天空 specular、Background、shadow subtraction、fog 与 sRGB shader 结构。
- 新增 `app/src/experience/world/GlobalGroundLayer.ts`：创建 2000×2000 平面，复制 GLB Ground 的世界变换，绑定投影阴影、共享 Lighting/Background、noise 与 resolution uniform。
- 更新 `app/src/experience/world/WatercolorView.ts`：初始化并挂载 `SourceGlobalGroundLayer`，隐藏 GLB 原始 Ground，随 update/resize 同步时间、fog 与 drawing-buffer 分辨率；Background fullscreen composite 和 Cutouts 保持各自职责。
- 更新 `app/scripts/qa-experience.mjs`：增加 global Ground 结构、shader、uniform、平面尺寸、renderOrder、阴影强度、共享材质和 resolution 门禁；同时把笔触/草层生命周期探针改为隔离自动刷新并记录生命周期峰值，避免机器负载和连续 rise→fall 造成误报。QA 断言没有放宽。

## 验证结果

- `npm exec -- tsc --noEmit`：通过。
- `node --check scripts/qa-experience.mjs`：通过。
- `npm run verify`：通过，Vite 构建成功，`verify:integrity` 为 73/73，只有既有 bundle chunk 大小提示。
- 最终 Chrome CDP QA：`app/.artifacts/qa/global-ground-2026-08-25-final10/report.json`，5 个视口 `passed: true`。
- 最终报告确认：Global Ground 五视口均存在且为 `2000×2000`、`renderOrder=-3`、`receiveShadow=true`、`uShadowStrength=0.9`；Cutouts、流体、Grass、相机、Full Paint、Poem、音频、FAQ、Restart、reduced-motion、资源失败和 context-loss 链路均通过；`consoleErrors=[]`、`remoteResources=[]`。

## 未完成的视觉收敛

源码职责已经恢复到可观测层级，但 Branch 不是“网页(1)”或根目录主工程的替代副本。后续仍需在 Branch 自己的边界内做同 seed 截图/像素差分，特别是 Ground fog 边界、基础亮度、投影阴影边缘、DPR>1 和横竖屏视觉一致性；这些不能由结构 QA 直接推出。
