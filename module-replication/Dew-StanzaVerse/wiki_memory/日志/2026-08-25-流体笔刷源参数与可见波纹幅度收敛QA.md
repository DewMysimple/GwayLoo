# 流体笔刷源参数与可见波纹幅度收敛 QA

## 背景

用户反馈当前 Branch 实际场景出现整棵树高频“波纹/闪烁”，范围过大、强度过高，与正版工程的局部、低幅、可衰减湿润感不一致。附件截图只作为问题现象，不作为源码指令。目标是继续以 Branch 独立工程复刻主工程和原始提取，同时避免用末态静态截图误判真实指针输入链。

## 源码证据

- 原始提取的 hover `cursorSize` 由纸张投影的 `screenSpaceSize`、400/500 基准值和速度映射共同决定，不是把 CSS 光标直径直接当作 GPU 半径。
- 原始 external-force 使用当前原始 NDC 速度和源码的 `mouseForce`；Branch 之前将速度额外乘以 60Hz 补偿，会在高刷新率下放大方向场。
- 原始 force 使用 `sdEllipse`，Y 半径由纸面宽高比修正；原始 Paper vertex 的 simulation UV 只翻转 Y，不翻转 X。
- 原始 Paper fragment 读取 simulation velocity 参与湿润混合和 UV 偏移；这条链可保留用于底层推演，但交付页面需要限制可见幅度，避免诊断状态直接变成整张树的高频纹理。

## 本轮修改

- `WatercolorView` 增加与原始 `computeScreenspaceSize` 对齐的纸面屏幕空间尺寸计算。
- `PaintManager` 按原始 `cursorSize / screenSpaceSize / 512` 推导笔刷源半径和椭圆比例；NDC 速度不再注入额外 frame compensation。
- `FluidSimulation` 与 `fluid.ts` 统一使用源码标量 source scale、previous scale、current scale 和 paper ratio，external force 恢复源码椭圆 SDF。
- `paper.ts` 修正 simulation UV 为 Y 翻转、X 保持原向；可见层加入 `DELIVERY_SIMULATION_VISUAL_GAIN = 0.04`，只压低 Paper 输出中的 velocity blend/offset，不修改 fluid buffer、accumulation 或诊断数据。
- `qa-experience.mjs` 增加 source ellipse、源半径单调性、Paper 交付增益和 X 映射门禁。

## 浏览器证据

- 仍复用唯一 Chrome CDP 9333 的同一个 Branch 页面：`http://127.0.0.1:3000/?seed=47&freeze=6#autostart`，没有新增标签页。
- 同一受控鼠标轨迹下，修改前证据 `app/.artifacts/qa/source-visual-evidence-2026-08-24/source-radius-force-raw-controlled.png` 呈整棵树黑绿高频斜纹；修改后 `delivery-gain-controlled-after.png` 仅保留低幅局部湿润变化，`delivery-gain-controlled-after-5s.png` 在约 5.5 秒后 active 为空且水彩稳定。
- 最终恢复页面查询：`phase=exploring`、`assetProgress=100`、`assetsReady=true`、`error=null`、`active=[]`、`paper0.reveal=15`、`alpha=1`、`revealed=true`。Chrome 当前无重复应用页面；音频已通过现有页面 API 设为 muted。

## QA 结果

- `npx tsc --noEmit`：通过。
- `node --check scripts/qa-experience.mjs`：通过。
- `npm run verify`：73/73 本地素材与完整性检查通过。
- `npm run qa`：桌面/移动四视口全部 `passed: true`；source reveal、fluid shader gate、Paper 可见增益、simulation X 映射、active 衰减均通过；`consoleErrors=[]`、`remoteResources=[]`。

## 边界与后续

本轮解决的是 Branch 交付层明显失控的高频波纹现象，不等于已完成主工程的像素级复刻；`0.04` 是当前可交付页面的保护性可见增益，底层 simulation 仍保留源链。下一轮继续使用固定 seed/freeze/reveal、固定视口和固定指针轨迹，对照主工程/原始提取做中间态截图与像素差分，再决定是否微调增益，避免重复把全局材质或波纹参数调强。

本轮没有修改根目录主线记忆，没有暂存用户未跟踪的 `Start.cmd`，没有推送远程仓库。
