# 自定义光标圆形指示器修复与 QA

## 问题

用户在 Branch 页面看到的自定义光标呈现为四角/断裂状，与原站的完整圆形指示器不一致。附件只作为现象证据，不改变源码基线和水彩渲染参数。

## 根因与修复

- Branch 保留了原站的双 SVG 光标 DOM，但光标 CSS 只实现了简化状态，没有明确恢复 `out-circle` 的完整圆环绘制属性、SVG 溢出可见性和画纸悬停态。
- `app/src/style.css` 现在对 `.circle` 明确设置透明填充、无 `stroke-dasharray`/`stroke-dashoffset`、圆端点/连接，并让 SVG `overflow: visible`；`.out-circle` 恢复完整圆环，`.in-circle` 保留中心点。
- 画纸悬停态恢复为完整白色圆形笔刷指示，不再用会误导为四角的简化状态；诗句悬停和按下状态仍独立过渡。
- `app/scripts/qa-experience.mjs` 新增桌面圆环、中心点、尺寸和 overflow 断言；移动端继续允许隐藏自定义光标。

## 验证

- `npm exec -- tsc --noEmit`：通过。
- `npm run build`：通过，Vite 58 modules；保留既有大 chunk warning。
- `node --check scripts/qa-experience.mjs`：通过。
- `git diff --check`：通过；仅有既有 LF/CRLF 提示。
- 固定 `?seed=47&freeze=6#autostart`、1440×900 的 Chrome CDP 定点验证：通过；光标 `95px`，`stroke-dasharray=none`、`stroke-dashoffset=0px`、`overflow=visible`，圆环实际完整，中心点存在，未改动纸片材质、波纹密度或 Reveal profile。

## 遗留

完整五视口 QA 尚未因本次光标小修单独重跑；后续统一 reveal 状态的回归应使用新增断言覆盖桌面/移动端光标契约。
