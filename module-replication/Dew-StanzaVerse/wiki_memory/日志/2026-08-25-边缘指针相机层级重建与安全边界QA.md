# 边缘指针相机层级重建与安全边界 QA

## 结论

本轮处理了用户反馈的“鼠标靠近屏幕边缘时相机脱轨、画面出现难看的视角”问题，并重新对照主工程原始提取确认相机不是简单的 world-space 位置旋转。

Branch 现在按源码的层级重建相机：烘焙的 `Camera_Action_Baked` 由独立 parent container 播放，实际渲染 PerspectiveCamera 作为 child；入口动画和指针视差只改 child camera 的局部 position/rotation，不再把已烘焙的相机世界位置绕场景原点旋转。桌面仍保留源码公开参数 `2.55° / 9.2° / 0.3`，移动端和 reduced-motion 仍禁用视差。

## 根因与源码证据

- Branch 旧实现先读取 `Camera_Animation_Baked` 的 world position/quaternion，再对渲染相机做 `position.applyQuaternion(...)` 和 `quaternion.premultiply(...)`；这会把相机位置绕世界原点一起旋转，正是边缘指针导致画面“脱轨”的直接原因。
- 原始提取 `sources/original-extraction/study/app.beautified.js` 的相机职责是新建 `Xb` container、把新建 PerspectiveCamera 加为 child，由 `Camera_Action_Baked` mixer 驱动 container，再在 `mouseMoveCamera` 中只对 child camera 的 rotation 做阻尼插值。
- 原始公开输入仍为 `targetRotateX = ndc.y * 2.55°`、`targetRotateY = -ndc.x * 9.2°`、`1-exp(-0.3*delta)`；GLB 中的动画为 `Camera_Action_Baked`，时长 `59.7666664` 秒，translation/quaternion 轨道对应 `Camera_Animation_Baked`。
- `three` 的 `PropertyBinding` 在节点名无法从新建 container 找到时回退到 mixer root，因此用新建 container 播放这组 source-shaped track 与源码语义一致。

## 本轮修改

- `app/src/experience/world/ScrollCamera.ts`
  - 改为 `_container -> PerspectiveCamera` 层级；baked clip 由 container 的 `AnimationMixer` 驱动。
  - 入口 position/rotation 改为 child camera 局部动画；指针 quaternion 只写入 child camera。
  - 从 GLB camera 定义读取 fov/near/far，不再固定覆盖裁剪参数。
  - 保留源码 `2.55 / 9.2 / 0.3` 参数，同时加入 Branch 交付保护边界 `POINTER_NDC_LIMIT=0.2`。这是为了窄视场下保持用户确认的稳定构图，不冒充主工程原始常量；若开放整屏 NDC，源码角度会把当前 Branch 的画面推到不可接受的边缘视角。
- `app/scripts/qa-experience.mjs`
  - 增加真实 pointer trajectory：中心 → 右下边缘 → 中心。
  - 门禁确认 `pointerPositionInvariant`，即边缘指针不改变相机的 baked world position；同时确认 source 参数、安全边界、移动端视差开关。

## 验证

- `npm exec tsc -- --noEmit`：通过。
- `npm run build`：通过；仅保留既有大 chunk warning。
- `npm run verify:integrity`：73/73 通过。
- `npm run qa`：通过，桌面/移动端完整 QA 报告 `passed: true`；Fluid、brush sample、Paper/Ground/Shadow、Full Paint、Poem、音频、Restart、降级、Context Loss、console errors 和 remote resources 均通过。
- Chrome CDP 9333：保留唯一 Branch 页面 `http://127.0.0.1:3000/?seed=47&freeze=6#autostart`，1440×900、`exploring`、加载遮罩隐藏；真实 pointer 探针生成了 `lastBrushSample`，中心到边缘的 camera local position delta 为 `0`，camera target 被限制为 `[0.2,-0.2]`。
- 边缘截图目视确认树、文字和地面仍保持在可交付构图中，没有旧版的横向脱轨；指针回到中心后页面保持正常。

## 边界与后续

本轮修复的是相机层级和边缘交互安全，不继续改动用户已经认可的水彩波纹材质与 `DELIVERY_SIMULATION_VISUAL_GAIN`。相机参数已经按主工程源码语义对齐，但 `0.2` 是 Branch 为交付构图增加的安全窗口；下一步仍是固定 seed/freeze/reveal/viewport 下与主工程中间态做截图或像素差分，不能把 Branch 自证 QA 宣称为正版像素级一致。
