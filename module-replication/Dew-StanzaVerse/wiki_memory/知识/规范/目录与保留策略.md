# 目录与保留策略

- `app/`：当前可执行源码；`node_modules`、`dist`、`.artifacts` 都可重新生成且不提交。
- `sources/`：只读原始镜像；不得修改。
- `archive/`：历史补丁证据；不参与运行。
- `evidence/`：已接受 QA、迁移和维护清单；保留历史，不覆盖。
- `wiki_memory/`：持续维护的协作知识与事件日志。

本仓库使用本地 Git 的 `main` 分支，不设置远程。首次基线提交包含应用源码、来源镜像、证据、归档、文档和工程记忆，不包含缓存、依赖或构建产物。
