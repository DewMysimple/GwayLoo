# ADR-004｜原始素材仅限本地实验，发布前完成清理

## 状态

`active`

## 背景

当前工程包含来自原始站点的文案、品牌名称、视觉媒体、字体、模型、音频和第三方资源。用户计划结合可复用资源和个人审美进行二次建设，但最终授权和发布范围尚未确认。

## 决策

在授权或替换完成前，工程默认只用于本地实验。公开部署或商用发布前，必须替换原始品牌与内容，审查媒体和字体来源，清理不必要的原站链接与兼容资源。

## 理由

- 避免把学习和复刻材料误当成可公开发布的原创资产。
- 让公开发布成为一个明确的验收阶段，而不是默认行为。

## 影响

- 当前记忆会保留来源和风险提示，但不记录或传播任何密钥、令牌。
- 发布检查必须覆盖 HTML 文案、图片、视频、音频、字体、模型、外链和静态页面。

## 验证方式

发布前进行一次素材清单、来源和品牌字符串审查，并将结果记录在单独的维护或发布日志中。
