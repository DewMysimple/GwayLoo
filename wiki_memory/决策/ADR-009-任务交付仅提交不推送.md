# ADR-009 任务交付仅提交不推送

## 决策

本项目每次完成任务后只创建本地 Git commit，不执行 `git push`，也不因任务自动创建新分支。网页与 Blender 继续共用当前 `main` 工程和提交历史。

## 边界

该规则适用于网页、Blender 工作台和混合任务。只有用户明确要求调整交付规则时，才允许推送或改变分支策略。
