# 已知问题

| 问题 | 影响 | 当前处理 |
| --- | --- | --- |
| 压缩 WebGL 运行时没有可维护源码 | 场景逻辑和画布内英文无法安全配置化 | 仅通过 `LegacyRuntimeBridge` 隔离，后续单独重写 |
| 旧运行时硬编码资源 URL | 兼容资源目录暂保留 `wp-content` 路径 | 通过 Vite `public` 静态路径提供，未来由场景清单接管 |
| 旧运行时依赖最小 DOM 契约 | 删除兼容节点可能导致初始化失败 | 契约集中于 `LegacyRuntimeBridge`，不散落到页面结构 |
| R3F 水彩着色与后处理尚未逐帧等价 | 不能安全切换默认运行时或删除旧部件 | 保持双轨，用 Playwright 与源码测量继续验收 |
| 动态 WebGL 帧存在时序差异 | 单纯像素截图可能产生误报 | 比较相机、物体边界、文字几何、交互阈值和稳定状态 |
| 原始素材尚未授权或替换 | 不能公开发布 | 保持仅本地实验 |
