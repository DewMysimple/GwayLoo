# 项目概览

## 项目名称

`Verminoble`。`David Whyte Experience` 是已归档的原始复刻基线名称。

## 当前目标

建设可渐进二次创作的个人审美沉浸体验站。兼容期忠实保留原版加载、诗句/场景、六组景观、声音、连续滚动，以及体验后的 Benefits、FAQ 与收尾内容。

## 当前阶段

React Three Fiber 已成为默认运行时并通过桌面、移动和低性能自动验收。`?runtime=legacy` 暂时保留压缩 WebGL 回退；人工视觉验收后执行旧脚本、旧样式、兼容 DOM 和 `/wp-content/` 的最终清除。

## 重要入口

- 开发：`npm run dev`
- 构建：`npm run build`
- 应用：`src/main.tsx`
- 页面：`src/features/experience/ExperiencePage.tsx`
- 文案与场景配置：`src/content/`
- 正式资源：`public/assets/`
- 临时回退：`public/wp-content/themes/davidwhyte/`
- R3F 运行时：`src/features/experience/r3f/`
- 本地三维二创：`scene_workbench/`
- 自动回归：`tests/e2e/`

## 边界

- Benefits、FAQ、订阅按钮及其英文是原版静态体验内容，不代表项目具备账户、商城、支付、订阅后端、WordPress 服务或第三方插件能力。
- 迁移前完整静态副本由本地 Git 标签 `baseline/static-replica-2026-08-22` 保存。
- 原始素材仅限本地实验，公开发布前必须完成替换或授权审查。
- `scene_workbench/` 是不被 Vite 和正式运行时引用的本地美术工作区；其中原素材副本与 Blender 文件不进入 Git。
