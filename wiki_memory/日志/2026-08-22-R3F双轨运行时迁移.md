# 2026-08-22｜R3F 双轨运行时迁移

- 类型：`feature`
- 状态：阶段完成，最终切换待视觉等价验收
- 目标：在不改变原版 UI 和交互的前提下建立 React Three Fiber 模块化运行时。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的边界

- `网页(1)` 只读，作为源码、DOM、排版、资源和交互事实基准。
- 默认运行时在 R3F 完整验收前保持 legacy。
- 订阅、赠送、邮箱、社交和奖项继续静态化，不发生导航。
- 不修改压缩 `app.js`，不提交 Git，不推送远程。

## 实施内容

- 增加 `?runtime=legacy` / `?runtime=r3f` 双轨选择和统一 `ExperienceRuntime` 配置边界。
- 建立 `ExperienceDefinition`、六场景清单、源图集切片、图层时序、尾部配置和 reducer 状态机。
- 新增 R3F GLB 相机动画、图集图层、KTX2、LUT、纹理、视频景观和音频加载控制。
- 保留黑色签名加载器与白色圆形资源加载器的先后阶段。
- 使用原生连续滚动连接沉浸区与 Benefits、五项 FAQ 和最终收尾。
- 将 FAQ 状态交由 React 管理，保留 Restart 有效并确保所有获准外链为静态文字。
- 增加 Vitest、资源完整性检查和 Playwright 桌面/移动回归。

## 诊断与修复

- 对照发现 `html lang="zh-CN"` 会把 30px 英文诗句的正常行高由约 34px 放大到 40px，进而改变换行和滚动总高度；恢复 `en-US` 后 legacy 与只读原版几何一致。
- 原版 Photoshop `ink.3DL` 的 8 点网格采用 146/147 混合舍入，Three 官方加载器拒绝解析；新增内存兼容表头后继续交由 `LUT3dlLoader` 解析，原文件和哈希不变。

## 验证摘要

- legacy 桌面与移动的文档高度、沉浸区高度、尾部起点和 FAQ 数量与只读原版一致。
- R3F 可完成双加载、连续正反向滚动、六景观进入/返回、声音状态、FAQ、Restart 和静态外链检查。
- 模型、视频、音频、字体、KTX2、LUT、纹理和 MSDF 资源进入清单检查。

## 遗留门槛

- R3F 的纸张、噪声、水彩 SDF、地面材质、LUT 后处理和景观热点几何仍需按源码测量实现逐帧等价。
- 在上述视觉门槛通过前，不切换默认运行时，不删除 `LegacyRuntimeBridge`、旧压缩资源或 `/wp-content/` 路径。

## 待确认长期记忆

- 无；双轨迁移与保留 legacy 的门槛已由本次实施计划确认。
