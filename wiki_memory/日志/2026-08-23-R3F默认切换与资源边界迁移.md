# 2026-08-23｜R3F 默认切换与资源边界迁移

- 时间：2026-08-23 02:05（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：继续清除正式运行链路中的旧架构、旧压缩产物依赖和不可维护边界，让 R3F 成为默认运行时。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 最终标准采用行为等价与 Verminoble 新视觉，不再要求旧引擎逐帧复刻。
- 新运行时资源迁至 `/assets/`，旧 `/wp-content/` 只为短期 legacy 回退保留。
- 当前先完成架构迁移，原始品牌、英文文案和媒体替换另设阶段。
- 采用分阶段切换：R3F 成为默认，`?runtime=legacy` 短期保留，人工视觉验收后执行最终删除。

## 主要变更

- 新增强类型 `ExperienceAssetManifest` 与统一时间线；R3F 模型、纹理、字体、音频和视频全部改用 `/assets/`。
- 将第一阶段加载器迁入 React 状态，删除新运行时的 `window.loaderProgress` 和自定义全局启动事件；legacy 全局变量只保留在兼容适配器。
- 默认运行时切换为 R3F，旧 CSS 与 `app.js` 仅在显式 legacy 回退时动态加载。
- 资源管线通过 Context 向水彩世界提供 atlas、mask、SDF、纸张、噪声、KTX2 和 LUT；新增可维护 ShaderMaterial 与性能分级参数。
- 为 R3F 页面尾部建立独立样式，解除对 524 KB 旧主题 CSS 的隐藏依赖。
- 新增架构边界检查，禁止新代码引用 `/wp-content/`、legacy 全局变量或旧 HTML 注入。
- 修复原 `typecheck` 脚本未实际检查引用项目的问题，并拆分应用代码、R3F 和 Three vendor chunk。

## 验证

- `npm run lint`：通过。
- `npm run typecheck`：通过。
- `npm run test`：8 个测试文件、14 项测试通过。
- `npm run check:architecture`：46 个可维护源码文件通过。
- `npm run check:assets`：56 个新运行时资源通过。
- `npm run build`：通过；R3F 应用自有 chunk 约 20 KB，Three 与 R3F 依赖独立分包。
- `npm run test:e2e`：桌面、移动和低性能共 15 项通过；默认 R3F 无 `/wp-content/`、外部请求、4xx 或控制台错误。
- 生成并检查完整页面截图，水彩世界与独立页面尾部均可见。

## 边界与下一步

- 旧 `app.js`、旧 CSS、隐藏 DOM 和 `/wp-content/` 仍为显式 legacy 回退保留；缺失的 `app/427.js` 未伪造或修补。
- 下一步是人工视觉验收默认 R3F；确认后删除 legacy 代码和旧资源树。
- 本轮未修改只读参考目录、Blender 文件或 `scene_workbench` 用户产物，未删除未跟踪的 `__pycache__`。

## 待确认长期记忆
