# WlopNap 源版本渲染链修复

## 问题

上一版独立实验页把原图先做 luminance 灰度，再用单个 dye 通道混回原色；这与源版本 `fullPaint` 的实现不同，导致灰态过暗、源纹理不可见、交互区域表现为普通圆形 reveal，并出现截图中的异常黑色横向条纹观感。

## 源代码核对结论

- 源版本全屏材质以 `uColor` 的浅灰纸面为 inactive state，不是原图 luminance 灰度。
- `uSimulation` 的通道契约为 `RG` 方向、`B` 速度、`A` 强度；全屏 shader 使用 `smoothstep(0., .1, data.b)` 控制图像混入和位移。
- 源版本 simulation manager 使用外力、平流、散度、压力迭代、梯度减法和 accumulation 多阶段 FBO 链，而不是单张染料纹理。
- fullPaint 使用纸张纹理；水彩图层还使用彩色噪声、法线和 dry/ink 3D LUT。
- 源版本的 cover 计算需要保持纹理宽高比；本实验页采用比例保持的宽屏 cover，宽度优先时只裁剪上下溢出，不拉伸图像。

## 变更

- 重写 `WlopNap/src/fluidSimulation.ts`，加入 velocity、divergence、pressure A/B、accumulation A/B 等 ping-pong pass。
- 重写 `WlopNap/src/revealShader.ts`，加入浅灰纸面、原图混合、纸张纹理/法线、彩色噪声、图像位移和 dry/ink LUT。
- 新增 `WlopNap/src/lut3d.ts`，解析源工程 `.3DL` 为 `Data3DTexture`。
- 更新 `WlopNap/src/wlopNapExperience.ts`，加载完整源纹理链并按原图真实尺寸设置 UV。
- 移除 vignette 的 multiply 黑化效果，避免额外压暗原图。
- 复制源纹理到独立页 `public/assets/`：paper texture、paper normal、watercolor noise、dry LUT、ink LUT。

## 验证

- `npm run dev -- --host 127.0.0.1`：运行中，地址为 `http://127.0.0.1:5173/`。
- 首页、原图、纸张、法线、噪声和两份 LUT 的本地 HTTP 请求均返回 200。
- Vite 热更新日志无编译错误。

## 遗留项

- 本轮没有修改主站 legacy `app.js` 或主站 R3F `VideoLandscape.tsx`；修复只作用于 WlopNap 独立实验页。
- LUT 的色彩观感与浏览器 WebGL2 实现有关，若要做到逐像素与原站完全一致，仍需在同一浏览器和视口下做截图比对。
