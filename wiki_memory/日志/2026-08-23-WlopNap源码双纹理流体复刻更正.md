# WlopNap 源码双纹理流体复刻更正

## 目标

纠正 WlopNap 独立页的黑屏、色彩偏移、错误 cover UV 和非源码交互，实现高亮白灰底图经鼠标局部流体恢复原图色彩，并以原工程 `Open the landscape` 的实际压缩源码和真实 `base/over` 视频为依据。

## 源码核对结论

- `Open the landscape` 全屏交互使用 `M5 full-paint` 双视频材质，而不是通用水彩纸张法线和 dry/ink LUT 材质。
- 原工程真实桌面素材包含 `videos/desktop/base/1.mp4` 与 `over/1.mp4`；抽帧确认二者是同一风景的浅色水洗版和完整颜料版。
- 局部混合公式为 `mix(paintColor, paintColor2, smoothstep(0., .1, data.b))`，随后只做中性的 ±5% 明度变化；`computeInkReveal` 使用 `noise/rgb-generated`。
- 全屏 `BatchInkSimulation` 的 pass 顺序为 external force、advection、divergence、pressure、gradient subtract、accumulation；默认参数为 `mouseForce=50`、`cursorSize=400`、`deceleration=.98`、`attenuation=.96`、`dt=.008`、`pressure.iterations=1`。
- advection 使用 `noise/rgb-fractal`，参数为 `randomDirection=.8`、noise scale `1/2`、`gapVelocityBoost=3`、`velocityThreshold=.05`、`intensityDim=.001`、`gapAmount=.468/.51`。
- 源码 cover UV 通过放大 scale 后除法居中采样；旧实现把裁剪方向写反，导致越界 clamp 和横向挤压观感。
- accumulation 的静止区 `B` 为 1，局部流动会使其下降；为满足“静止白灰、鼠标显原色”，原图必须放第一纹理槽，白灰图放第二纹理槽，同时保持源码 mix 公式不变。

## 变更

- 重写 `WlopNap/src/fluidSimulation.ts` 为源码六 pass 的单全屏适配，使用半浮点 ping-pong FBO、源码噪声和原始常量。
- 重写 `WlopNap/src/revealShader.ts`，保留源码 cover UV、双纹理混合、`computeInkReveal`、`#fff7e5` 背景和 reveal point 生成逻辑。
- 新增 `WlopNap/src/whiteGrayBaseTexture.ts`。原站拥有作者预制的两份视频，而 WLOP 只有一张图，因此只在加载时生成缺失的中性白灰 base；原图 RGB 不经过 LUT、色相变化或纸张乘色。
- 更新 `WlopNap/src/wlopNapExperience.ts`，按源码创建宽屏 1024 基准 simulation、使用阻尼指针坐标并加载 `rgb-fractal` 与 `rgb-generated` 两类噪声。
- 将源码 `rgb-fractal.png` 复制为 `public/assets/fluid-noise.png`，删除错误方案遗留的 LUT loader 和未使用的 paper/LUT 副本。
- 修正 GLSL3 主 shader 重复 attribute 声明导致的全黑画布，并修正单实例外力 shader 使用保留字 `active` 导致流体 pass 编译失败的问题。
- 页面加载底色和 UI 文本调整为适配白灰画面的白底/深灰组合。

## 验证

- `npm run build`：TypeScript 和 Vite 构建通过。
- Chrome 真实 WebGL 运行日志：无 shader 编译错误或 JavaScript runtime error。
- 初始截图：3840×2160 原图按源码 cover UV 等比铺满，宽屏只裁剪上下，不发生横向压缩；画面为高亮白灰。
- 自动鼠标轨迹截图：轨迹附近出现带 `rgb-fractal` 缺口和扩散的原图冷蓝、肤色与暗部，静止区域维持白灰。
- `Reset wash` 可清空所有 velocity、pressure 和 accumulation FBO。

## 遗留项

- 原站的 base/over 是作者分别制作的动态视频；WLOP 只提供一张照片，因此白灰 base 是本实验页唯一的素材适配步骤。若未来提供与原图对应的作者制 base/over 素材，可直接替换两个纹理而无需改 shader 或流体链。
- 本轮只修改 WlopNap 独立实验页，不修改 legacy `app.js`、主站运行时或桌面只读源目录。
