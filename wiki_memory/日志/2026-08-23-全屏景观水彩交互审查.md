# 2026-08-23｜全屏景观水彩交互审查

- 时间：2026-08-23（北京时间）
- 类型：`discussion`
- 状态：`完成`
- 目标：确认子页面“Open the landscape”的鼠标驱动局部流体模拟是否与主页面使用同一份代码。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的结论

- 默认 `legacy` 运行时复用同一个 `BatchInkSimulation` 管理器、同一个累积反馈纹理输出和同一组流体 pass。
- 普通水彩图层使用每层的 simulation instance：鼠标先经 raycast 命中图层，再将局部 UV 转成该层的模拟坐标。
- “Open the landscape”切换到同一管理器创建的 `fullScreenInstance`：使用全局 NDC 鼠标坐标，不再依赖某个图层的 raycast 命中。
- 全屏景观材质通过 `uSimulationRemap` 从同一份模拟输出中采样全屏区域，并把模拟结果用于 base/over 景观视频的水彩显现与扰动。
- 全屏景观显示期间，普通图层的 paint interaction 和普通层 simulation instance 会被停用或隐藏；因此这是同一模拟系统的模式切换，不是两套流体引擎同时叠加。
- 当前 `?runtime=r3f` 预览尚未实现上述复用：`VideoLandscape.tsx` 仅使用两个 `VideoTexture`，通过鼠标横向位置改变 over 视频透明度，没有 `BatchInkSimulation`、GPU 流体纹理或 full-screen remap。

## 检查与操作

- 复查 `public/wp-content/themes/davidwhyte/app.js` 中 `BatchInkSimulation` 的普通层实例与 `fullScreenInstance` 创建逻辑。
