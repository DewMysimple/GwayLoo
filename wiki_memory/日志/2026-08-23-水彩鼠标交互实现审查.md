# 2026-08-23｜水彩鼠标交互实现审查

- 时间：2026-08-23（北京时间）
- 类型：`discussion`
- 状态：`完成`
- 目标：说明网页中鼠标针对水彩图层移动时的交互实现链路。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 默认 `legacy` 运行时的水彩交互由 `public/wp-content/themes/davidwhyte/app.js` 中的 WebGL 批量墨水模拟负责。
- 交互不是 CSS hover；鼠标命中当前图层后，将局部 UV 写入 GPU 反馈纹理，再由水彩 shader 读取速度和强度。
- R3F 运行时目前只复用了 GLB、图集遮罩和图层显隐/相机动画，尚未实现这套逐帧鼠标水彩模拟。

## 检查与操作

- 读取工程记忆中的当前状态、系统架构、约束、待办、R3F 双轨决策与体验运行时知识页。
- 检查 `LegacyRuntimeBridge` 的兼容 DOM 与脚本加载路径。
- 静态审查 legacy bundle 中的 `BatchInkSimulation`、每层 simulation instance、paint manager raycast、`externalForce`/advection/pressure/gradient/accumulation passes，以及水彩 paint shader 的 simulation 采样。
- 对照 `src/features/experience/r3f/LandscapeWorld.tsx`，确认迁移运行时当前没有鼠标射线与流体纹理反馈。

## 问题、结果与下一步

- 结果：已确认交互由“命中图层局部坐标 → GPU 流体反馈 → 水彩 shader 混合/微扰”组成。
- 遗留问题：legacy bundle 已压缩，后续若迁移到 R3F，仍需通过逐帧视觉回归确认所有 shader 参数与资源映射。
- 下一步：如需迁移，可把该链路拆成 pointer raycast、per-layer simulation atlas、fluid passes、paint material 四个 R3F 模块。
