# GwayLoo 品牌迁移

## 目标

将应用品牌从 `Verminoble` 更新为 `GwayLoo`，与新的 GitHub 仓库名称保持一致。

## 确认的决策

- 对外展示品牌使用 `GwayLoo`。
- npm 包名、DOM 根节点、运行时事件、运行时缓存键和测试钩子使用小写标识 `gwayloo`。
- `/wp-content/themes/davidwhyte`、历史日志、基线标签以及 Blender 主文件的既有文件名属于兼容或历史标识，本次保留。

## 检查范围

- 页面标题、描述和 React 根节点。
- `package.json`、`package-lock.json`、体验文案、字体族名称、运行时钩子和测试标识。
- README、执行计划、工作区说明、当前状态和 Agent 入口记忆。
- 搜索剩余品牌引用，确认仅保留兼容/历史工件标识。

## 变更

- 应用展示名称、无障碍名称和页面元数据改为 `GwayLoo`。
- React 根节点从 `verminoble-app` 改为 `gwayloo-app`。
- boot 事件、legacy runtime 脚本 ID、全局 Promise 键和 E2E 播放计数键改为 `gwayloo` 前缀。
- npm 包名改为 `gwayloo`。
- 当前文档和工程记忆的项目主名改为 `GwayLoo`。

## 验证摘要

- `npm run lint`：通过。
- `npm run typecheck`：通过。
- `npm run test`：5 个测试文件、11 个测试通过。
- `npm run check:assets`：55 个体验媒体文件检查通过。
- `npm run build`：通过。
- `npm run test:e2e`：10 个用例通过。
- `wiki_memory/工具/memory_lint.py check`：通过。

## 遗留问题和下一步

- 工作区目录仍为本地路径 `Verminoble`，Blender 主文件仍为 `Verminoble_Scene_Mirror_5_0.blend`；如需改名，应作为独立文件迁移处理并同步所有生成脚本与报告。
