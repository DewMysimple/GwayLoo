# 任务交付仅提交不推送

## 目标

将用户确认的 Git 交付边界写入整个 Verminoble 工程，避免后续任务重复询问或意外推送远程仓库。

## 确认的规则

- 每次任务完成后只创建本地 Git commit。
- 不执行 `git push`。
- 不自动创建新分支；网页与 Blender 工作台继续共用 `main`。
- 规则同时适用于网页、Blender 工作台和混合任务。

## 文件变更

- 根 `AGENTS.md` 增加项目级交付规则。
- `blender_scenebench/AGENTS.md` 增加 Blender 工作台侧的同一规则。
- [[决策/ADR-009-任务交付仅提交不推送|ADR-009]] 固化长期决策。

## 结果

后续任务默认在当前分支完成本地提交，不推送远程；只有用户明确改变规则时才调整。
