# 网页与 Blender 工程记忆分流

## 目标

将 Blender 工作台重命名为 `blender_scenebench`，并建立按任务范围分流的工程记忆，同时保持网页项目与 Blender 工作台在同一个 `main` 工程中同步开发。

## 确认的边界

- 不创建新的 Git 支线、独立仓库、子模块或远程仓库。
- 网页任务继续使用主线 `wiki_memory/`。
- Blender 任务使用 `blender_scenebench/wiki_memory/`。
- 混合任务分别在两套记忆中记录对应范围。
- `module-replication/` 的独立支线规则不适用于 Blender 工作台，本次未修改其目录或 Git 规则。

## 主线变更

- 将 `scene_workbench/` 原地重命名为 `blender_scenebench/`，保留 `.blend`、脚本、报告、清单以及本地忽略目录。
- 更新 README、执行计划、ESLint 忽略项、当前状态和工作台命令中的有效路径。
- 主线 MOC 不再收录 Blender 专属历史日志；主线只保留网页资源事实与工作台边界。
- Blender 专属历史日志迁移到 `blender_scenebench/wiki_memory/日志/`，正文中的旧目录名作为历史事实保留。

## 验证摘要

目录重命名保持了 `.blend` 文件的文件名和目录深度，内部指向 `public/.../xp` 的相对资源路径无需重写；后续记忆体检、网页构建和 Blender 验证负责确认路径与行为未回归。
