# 体验运行时

## 一句话结论

体验通过统一配置边界提供 legacy 与 R3F 双轨运行时。默认 legacy 保持原版可运行基线，`?runtime=r3f` 用于模块化新引擎回归。

## 模块关系

- `src/features/experience/LegacyRuntimeBridge.tsx`：渲染兼容 DOM，加载脚本并显示运行时错误。
- `src/features/experience/legacy-runtime.ts`：一次性注入 `app.js`，避免重复初始化。
- `public/wp-content/themes/davidwhyte/app.js`：旧 Canvas/WebGL、视频纹理、音频和全屏景观状态。
- `src/content/experience.ts`：加载文案、控制文案和诗句。
- `src/features/experience/r3f/`：R3F 场景、资源、视频景观与可回归的新运行时。
- `src/features/experience/runtime/audio.ts`：在真实用户手势中解锁背景音乐，并管理循环音轨和反馈音效。
- `src/features/experience/SourceSoundControl.tsx`：从原版源码恢复的三段波形声音控件。
- `src/features/experience/OriginalExperienceTail.tsx`：尾部 Benefits、FAQ 与收尾；legacy 交互由旧脚本控制，R3F 由 React 控制。

## 约束

- 不在 React StrictMode 下加载旧脚本。
- 不直接改压缩脚本。
- Canvas 内部英文和资源切换仍由旧脚本控制，直到新引擎实现。
- 兼容组件只保留必要 DOM，不恢复 WordPress 页面外壳。
- 浏览器有声媒体必须在用户点击后解锁；不能用挂载后的异步 effect 代替该手势。
- legacy FAQ 不绑定 React 点击，避免与旧脚本重复切换；R3F FAQ 必须保留原版 0.8 秒高度动画。
