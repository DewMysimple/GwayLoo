# 内容与页面配置

## 一句话结论

可见页面内容不再存于大型 HTML 快照，而是由 React 组件和 `src/content/experience.ts` 的强类型配置提供。

## 编辑位置

- `experienceCopy`：品牌名、加载提示、返回、声音、重启和三段文字。
- `ExperiencePage`：当前单页体验的 React 组合入口。
- `LegacyRuntimeBridge`：只有在兼容旧引擎所需 DOM 改变时才编辑。
- `OriginalExperienceTail`：按只读基线保留 Benefits、FAQ 和体验收尾的 DOM、文案与交互契约。

## 注意

- Benefits、FAQ、订阅按钮和原站链接是静态参考内容；没有对应的账户、商城、支付、订阅后端或 WordPress 服务。
- `OriginalExperienceTail` 不渲染任何锚点：订阅、赠送、邮箱、Facebook/X 和奖项名称使用静态 `span` 保持原版视觉，但不能导航；FAQ 展开和末尾 Restart 保持有效。
- 画布内部标题和 CTA 仍在压缩脚本中，不能误认为已经由配置接管。
- 后续新增页面时再引入路由，不为当前单页体验预设空路由架构。
