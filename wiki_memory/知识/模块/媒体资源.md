# 媒体资源

## 一句话结论

模型、纹理、字体、视频和音频已迁入 Vite `public` 目录，并通过保留旧 URL 服务压缩 WebGL 引擎。

## 路径

| 资源 | 路径 |
| --- | --- |
| 兼容运行时 | `public/wp-content/themes/davidwhyte/app.js` |
| 视频 | `public/wp-content/themes/davidwhyte/resources/assets/xp/videos/` |
| 音频 | `public/wp-content/themes/davidwhyte/resources/assets/xp/sounds/` |
| 模型、纹理、LUT、MSDF | `public/wp-content/themes/davidwhyte/resources/assets/xp/` |
| 字体 | `public/wp-content/themes/davidwhyte/resources/assets/fonts/` |
| Blender 工作台边界 | `blender_scenebench/` |

## 当前映射

`src/content/scenes.ts` 记录 1-6 场景的 desktop/mobile、base/over 路径，并由 `npm run check:assets` 检查 24 个视频和 5 个音频文件。

Blender 工作台不参与网页运行，网页资源事实仍以 `public/`、`src/content/` 和 `npm run check:assets` 为准。Blender 场景结构、材质映射、资产可移植性和重建验证细节统一记录在 `blender_scenebench/wiki_memory/`；这里仅保留网页侧的资源边界。

## 注意

- 场景清单尚不驱动压缩引擎，替换视频必须保留当前命名。
- 所有原始资源默认仅限本地参考。
- WebGL 自定义 SDF、水彩、纸张和 LUT 后处理与 Blender 渲染器不存在逐像素等价保证；原始输入与参数必须保留，不能用视觉猜测替代。
