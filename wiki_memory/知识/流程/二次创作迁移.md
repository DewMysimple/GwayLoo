# 二次创作迁移

## 当前阶段

R3F 已成为默认运行时，正式资源、时间线、启动状态、水彩材质和页面尾部均进入可维护模块。旧 WebGL 仅作为显式短期回退存在。

## 后续顺序

1. 用原创资源替换六组视频、音频、模型、纹理和字体，并记录来源。
2. 人工验收当前默认 R3F 的视觉与交互。
3. 删除 `LegacyRuntimeBridge`、旧压缩产物、旧样式和 `/wp-content/`。
4. 将剩余原始英文、品牌和媒体替换为 Verminoble 内容。
5. 根据内容规模决定是否增加路由或 CMS。

## 原则

每一步都必须保留可验证的桌面和移动体验，不能把原始素材直接当作可公开品牌资产。
