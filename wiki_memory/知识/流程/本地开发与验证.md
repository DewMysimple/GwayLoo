# 本地开发与验证

## 标准流程

1. `npm install`
2. `npm run dev`
3. 使用 Vite 显示的本地地址访问页面。
4. 依次运行 `npm run lint`、`npm run typecheck`、`npm run test`、`npm run check:architecture`、`npm run check:assets`、`npm run build`。
5. 使用 `npm run preview` 检查生产构建。

## 体验 smoke test

- 桌面与移动视口均能完成加载。
- 三段文字可显示，声音可切换。
- 六组场景可进入 “Open the landscape” 全屏画面并返回。
- 视频 base/over 和音频没有 404。
- 默认 R3F 不请求 `/wp-content/`、外部域名或 WordPress 插件。

## 注意

不使用 `file://` 或旧的 Python HTTP 服务作为正式开发入口。
