# 资源替换规范

## 当前规则

- 优先在 `src/content/scenes.ts` 更新资源清单。
- 在旧引擎被重写前，物理文件必须保持 `desktop/mobile`、`base/over` 与 `1-6` 的目录和名称。
- 每个场景替换四个视频文件，并检查移动端版本。
- 音频、模型、纹理、字体和 LUT 的来源、格式和授权状态必须记录。

## 验证

- 执行 `npm run check:assets`。
- 通过 `npm run dev` 分别检查桌面和移动端。
- 确认进入全屏景观、返回和声音切换不中断。

## 迁移后

新场景引擎落地后，`sceneManifest` 将成为唯一运行时映射，届时可停止旧路径兼容。
