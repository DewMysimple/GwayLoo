# 本地运行与发布边界

## 本地运行

- 开发：`npm run dev`
- 构建：`npm run build`
- 预览：`npm run preview`
- 回退基线：`git show baseline/static-replica-2026-08-22`

## 发布边界

当前构建仅支持本地实验。公开部署前必须替换或确认视频、音频、模型、纹理、字体、文案和外链的授权，并完成浏览器体验测试。

## 不包含的能力

当前没有账户、支付、商城、表单处理、数据库、CMS 或后台接口。
