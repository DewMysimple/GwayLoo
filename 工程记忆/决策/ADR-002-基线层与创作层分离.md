# ADR-002｜分离原始复刻基线与 Verminoble 创作层

## 状态

`active`

## 决策

工程持续采用两层模型：

- **基线层**：本地 Git 标签中的完整静态快照，以及当前 `public` 中临时兼容的运行时和资源命名约定。
- **创作层**：Verminoble 的 React 页面、中文内容、视觉系统、媒体映射和新架构。

创作层的决策和知识必须说明它替换或复用的基线部分。

## 理由

- 保留原始交互和视觉参考，但不让 WordPress 外壳继续主导应用。
- 允许逐步替换资源，不让原创内容依赖不可维护的硬编码。
- 为未来的可维护场景引擎保留清晰边界。

## 验证方式

每次创作任务都应能说明：修改的是哪一层、是否影响兼容运行链路、是否需要更新资源映射。
