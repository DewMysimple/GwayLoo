# ADR-003｜采用内容与资源配置化的渐进式替换策略

## 状态

`active`

## 决策

中文页面文案存于 `src/content/experience.ts`，场景清单存于 `src/content/scenes.ts`，主题令牌存于 `src/styles/tokens.css`。后续优先让场景清单实际驱动新的加载器，再替换场景行为和核心交互逻辑。

旧引擎被重写前，保持 `desktop/mobile`、`base/over` 和 `1-6` 的媒体路径兼容。

## 理由

- 替换美术和文字时减少对压缩核心脚本的依赖。
- 让可复用资源与具体站点内容分离。
- 以可验证的小步迁移降低 WebGL 回归风险。

## 影响

- 短期会同时存在旧运行时内置数据和新的 React 配置数据。
- `sceneManifest` 当前用于资源验证，尚未驱动旧引擎。
- 每次抽离都需要同步更新模块知识和迁移日志。

## 验证方式

运行资源检查，并在桌面与移动端分别验证替代媒体不会中断场景。
