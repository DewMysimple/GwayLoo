# 当前约束

## 技术

- 新页面、文案和控制只通过 React 模块与 `src/content/` 维护。
- 不直接格式化或编辑压缩的 `public/wp-content/themes/davidwhyte/app.js`。
- 旧运行时只能由 `LegacyRuntimeBridge` 加载；不要在其他组件中直接操作其全局状态。
- 不使用 React StrictMode 包裹根节点，避免旧运行时重复初始化。
- 兼容期内，原版可见 UI、文案与交互以用户提供的只读源码为事实依据；未经明确授权不得改写。
- 光标、双阶段加载器、诗句 DOM、`OriginalExperienceTail` 和整页滚动几何属于旧运行时契约，变更后必须进行浏览器级回归。

## 资源

- 引擎重写前，视频必须保留 `desktop/mobile`、`base/over` 和 `1-6` 的名称与路径。
- 每次资源变更后运行 `npm run check:assets`，并在桌面和移动视口验证体验。
- 原始媒体、字体、模型和画布内英文仅限本地参考，不能默认公开使用。

## 产品

- 原版 Benefits、FAQ、订阅按钮与体验收尾按静态参考保留，不把这些界面误认为可用的订阅、账户、商城、支付或 WordPress 后端能力。
- 尾部的订阅、赠送、邮箱、社交分享和奖项外链只显示原版文字或图标，不响应点击、不打开站内或站外页面。
- “Open the landscape” 是首页内部全屏状态，不是新路由或独立页面。
