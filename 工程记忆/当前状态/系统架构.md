# 系统架构

## 架构概览

根目录是 Vite + React + TypeScript 单页应用。页面代码、可编辑内容、主题令牌和体验特性相互分离；当前不使用路由、后端或 CMS。

| 模块 | 职责 | 入口 |
| --- | --- | --- |
| 应用壳 | React 挂载与页面组合 | `src/main.tsx`、`src/app/` |
| 内容配置 | 中文文案、诗句和六场景媒体清单 | `src/content/` |
| 体验特性 | React 页面与旧运行时生命周期 | `src/features/experience/` |
| 主题样式 | 颜色、层级、响应式与无障碍降级 | `src/styles/` |
| 兼容资源 | 压缩 WebGL、样式、模型、纹理、视频和音频 | `public/wp-content/themes/davidwhyte/` |

## 体验运行时

`LegacyRuntimeBridge` 是旧运行时的唯一入口。它渲染 Canvas、隐藏视频/音频、加载器、光标和最小兼容节点，再动态加载压缩 `app.js`。React 不直接修改该脚本。

`OriginalExperienceTail` 按只读基线源码渲染沉浸区之后的 Benefits、FAQ 与体验收尾。该区块属于连续滚动和旧运行时的 DOM 契约，但其中链接与文案只是静态参考，不提供订阅或账户服务。

旧脚本仍把资源 URL 和部分画布文字写死，因此保留 `wp-content/themes/davidwhyte` 作为 Vite 静态兼容路径。这里不再包含 WordPress 页面、插件或服务端能力。

## 数据流

`experienceCopy` 驱动中文加载、控制与三段文字。`sceneManifest` 记录六个场景的 desktop/mobile、base/over 视频映射，并由 `check:assets` 验证文件存在。旧引擎重写前，实际视频切换仍由其内置映射完成。

## 验证

按顺序执行：`npm run lint`、`npm run typecheck`、`npm run test`、`npm run check:assets`、`npm run build`。
