# 项目概览

> 这是 Agent 每次工作首先需要理解的项目摘要。保持简短，只记录当前有效事实。

## 项目名称

`Verminoble`。

- `Dew-StanzaVerse`：本地工作目录名。
- `David Whyte Experience`：原始站点复刻基线名称。

## 项目目标

在可运行的原始沉浸式站点复刻之上，逐步建设个人审美品牌体验站。后续重点是替换美术图层、文案、音频和场景内容，并将可复用资源从当前页面和压缩脚本中抽离出来。

## 当前阶段

本地静态复刻基线阶段，尚未开始正式品牌二次创作。当前默认只用于本地实验。

## 主要用户或使用者

当前为项目创建者和 Agent 的内部开发工程。最终受众、品牌定位和公开发布范围尚未确认。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `index.html` | 页面入口和当前静态内容快照 |
| `wp-content/themes/davidwhyte/` | 主题样式、核心运行脚本和体验资源 |
| `wp-content/themes/davidwhyte/resources/assets/xp/` | 模型、纹理、视频、音频、LUT 和文字纹理 |
| `wp-content/plugins/` | 本地化的 WooCommerce、MemberPress 等兼容资源 |
| `mapbox-gl-js/`、`dash.js/`、`npm/`、`clover/` | 原站引用的本地化第三方资源 |
| `当前状态/`、`决策/`、`知识/`、`日志/` | 工程 Agent 记忆系统 |

## 重要入口

- 启动：`python -m http.server 8787`
- 访问：`http://127.0.0.1:8787/index.html`
- 主运行时：`wp-content/themes/davidwhyte/app.js`
- 主样式：`wp-content/themes/davidwhyte/style.css`
