# 2026-08-22｜React 架构迁移

- 类型：`feature`
- 状态：完成
- 目标：将静态 WordPress 快照改造为可通过 npm 开发的 React 模块化沉浸体验。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 只保留沉浸式 Companion Portal 体验与六组 “Open the landscape” 全屏景观。
- 不新增独立景观路由，不保留订阅、账户、商城、支付、FAQ 或 WordPress 导航。
- 旧运行时通过 React 兼容桥接暂存，画布内英文暂作本地参考。
- 原始完整快照固定在本地 Git 标签 `baseline/static-replica-2026-08-22`。
- 本轮不创建 Git 提交，也不推送远程。

## 文件变更

- 新增 Vite + React + TypeScript 应用、npm 脚本、ESLint、Vitest、资源检查脚本和中文内容配置。
- 将旧 WebGL、样式及必要素材迁入 `public/wp-content/themes/davidwhyte/`。
- 移除 WordPress 插件、账户/商城/支付相关静态外壳与第三方兼容资源。
- 重写根目录 README，更新当前状态和架构决策。

## 测试与验证

- `npm run lint` 通过。
- `npm run typecheck` 通过。
- `npm run test` 通过。
- `npm run check:assets` 通过，检查 29 个视频和音频文件。
- `npm run build` 通过。
- Vite 服务下入口、运行时、样式和桌面/移动代表性视频返回 HTTP 200。

## 待确认长期记忆

- 未来是否采用 React Three Fiber 替换当前压缩 WebGL 引擎。
- 原创品牌视觉、场景文案和公开发布范围。

## 结果与下一步

- 结果：React 主架构已落地，旧运行时不再决定页面和内容结构。
- 遗留问题：六场景的 GPU 交互仍需浏览器人工 smoke test；原始素材仍不可公开发布。
- 下一步：替换原创素材并逐步实现可维护场景引擎。
