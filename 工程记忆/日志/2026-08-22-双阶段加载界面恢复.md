# 2026-08-22｜双阶段加载界面恢复

- 类型：`bug`
- 状态：完成
- 目标：修复 React 迁移后体验卡在空白加载画面、原版双阶段加载界面缺失的问题。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 检查范围

- 只读核对用户提供的原始网页副本与本地归档基线。
- 核对 React DOM 桥接、全局加载器、体验加载器、旧运行时注入时机以及浏览器实际渲染顺序。
- 原始参考副本未被修改、移动或删除。

## 根因

- React 迁移时将原版第一层黑色签名加载器误当作 WordPress 外壳隐藏，仅保留了第二层体验加载器的兼容节点。
- 第二层加载器文案和默认文字颜色被新内容配置与深色主题默认值覆盖，不再忠于原版。
- 旧压缩运行时依赖原版 Cursor 的 `inner-circle`、`outer-circle` 节点和页面加载完成时序；兼容 DOM 缺失会触发空引用并中断初始化。

## 文件变更

- 在入口恢复原版黑底 David Whyte 签名、进度线及 `loaderProgress` 加载流程。
- 恢复第二层圆形 `Loading`、原始说明文字、`See the poems`、`Back` 和 `Scroll to explore`。
- 移除 React 桥接中重复且隐藏的全局加载器节点，避免重复 `id` 与错误状态覆盖。
- 保留旧运行时延迟到 `window.load` 后注入的竞态修复，保留原版 Cursor DOM 契约。
- 移除会把原版默认文字强制变白的全局深色 `color-scheme`。
- 没有修改压缩 `app.js`，没有重绘或改造原版画布、美术和交互界面。

## 测试与验证

- 浏览器无缓存加载验证：先显示黑色签名加载器，再显示浅色圆形加载器，最后进入树景。
- 第二阶段加载结束后，Canvas 尺寸正常，原版场景能够显示。
- `npm run lint`、`npm run typecheck`、`npm run test`、`npm run check:assets`、`npm run build` 全部通过。

## 待确认长期记忆

- 后续 React 迭代应把用户提供的原始网页副本作为只读视觉与 DOM 参考；任何可见 UI、文案或交互变化必须先获得用户明确授权。
- 旧运行时仍存在期间，Cursor、全局加载器和 Experience 相关 DOM 是兼容契约，重构前必须进行浏览器级回归验证。

## 结果与下一步

- 结果：原版双阶段加载顺序与样式已恢复，加载卡死问题已修复。
- 遗留问题：旧运行时仍为压缩产物，React 桥接层需要继续保持严格的原始 DOM 契约。
- Git：本轮不创建提交，不推送远程。
