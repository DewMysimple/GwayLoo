# 2026-08-22｜诗句字号与滚动交互恢复

- 类型：bug
- 状态：完成
- 目标：恢复 React 迁移后偏小的画布诗句字号，以及失效的原版滚轮推进交互。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 检查与根因

- 只读核对原始网页副本中的体验 DOM、原始样式与压缩运行时；不根据截图猜测字号，不应用视觉重设计。
- React 桥接层曾把原始三段英文诗句及其 div、p、br 层级改成较短的中文 span 网格。
- 旧 WebGL 运行时依赖诗句 DOM 的真实排版尺寸。错误 DOM 令测量宽度由原版 390px 缩至 210px，测量高度由 1764px 缩至 772px。
- 同一改写把体验文档总高度压到与视口相同，滚动上限为零，Lenis 无法推进场景。

## 文件变更

- src/content/experience.ts：恢复原版三段诗句内容和受信任的原始测量标记。
- src/features/experience/LegacyRuntimeBridge.tsx：按原版子节点结构渲染诗句测量 DOM。
- src/features/experience/experience-compat.css：移除迁移时新增的诗句网格覆盖。
- src/features/experience/ExperiencePage.test.tsx：增加原版诗句结构回归断言。
- 未修改压缩 app.js，未添加或重绘任何可见 UI。

## 验证与结果

- 恢复后测量宽度 390px、诗句区高度 1764px、内部测量高度 1620px，与原版一致。
- 同视口文档高度由 1354px 恢复为 2273px，重新形成有效滚动范围。
- 真实滚轮输入可把画面从初始雾层推进到树景、诗句和 “Open the landscape”；首段诗句字号与原版一致。
- lint、typecheck、test、29 项资源检查与生产构建全部通过。
- 只读参考副本未修改；本轮未创建提交，未推送远程。

- 无。用户已明确确认：未经授权不得改变原版可见 UI 与交互；兼容期以只读源码为事实依据。
