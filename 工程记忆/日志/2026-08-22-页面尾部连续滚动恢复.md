# 2026-08-22｜页面尾部连续滚动恢复

- 类型：bug
- 状态：完成
- 目标：修复第三个景观结束后滚动提前终止，恢复原版沉浸区之后的完整连续内容。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 检查与根因

- 只读核对原始网页副本中的页面结构、样式和运行时；未修改参考目录，未根据截图重新设计。
- React 迁移曾把原版 `advantages-section` 替换为绝对定位的 1px 隐藏兼容壳。
- 隐藏壳不参与文档高度，导致页面在第三段诗句与景观结束时到达滚动上限；旧 WebGL 本身没有卡死。
- 原版在 `.xp-section` 之后还有 Benefits、五项 FAQ 和体验收尾，这些内容同时构成连续滚动几何与旧组件初始化契约。

## 文件变更

- `src/features/experience/OriginalExperienceTail.tsx`：以 React 组件恢复原版 Benefits、FAQ、静态链接和体验收尾 DOM。
- `src/features/experience/LegacyRuntimeBridge.tsx`：用真实尾部替换隐藏兼容壳。
- `src/features/experience/experience-compat.css`：移除隐藏尾部规则，仅限制横向溢出。
- `src/features/experience/ExperiencePage.test.tsx`：增加页面尾部、FAQ 数量与重启控件的结构回归断言。
- `README.md`：说明静态原版尾部与不可用后端能力之间的边界。
- 未修改压缩 `app.js`，未修改原始媒体。

## 浏览器回归

- 同一 1440×900 视口下，当前 React 页面与只读原版的关键几何完全一致：沉浸区 2046px，尾部起点 2036px，尾部高度 4004.375px，FAQ 起点 3765.875px，文档总高度 6050px。
- 真实滚轮输入可从第三个景观继续到 Benefits、FAQ 与最终体验收尾。
- FAQ 的原版 View/Close 交互可展开，首项展开后带有原运行时的 `open` 状态与 87.8125px 内容高度。
- 原版“Restart the experience”仅恢复在源码规定的最终收尾位置，没有新增中文悬浮或横条按钮。

## 结果与边界

- 页面尾部的可见文案和链接是本地源码参考，不代表账户、订阅、商城、支付或 WordPress 后端恢复。
- 只读参考副本未修改；本轮不创建提交，不推送远程。
