# 体验运行时

## 一句话结论

React 的 `LegacyRuntimeBridge` 是当前体验运行时的唯一入口。它将压缩 WebGL 引擎限制在一个可替换的特性模块内。

## 模块关系

- `src/features/experience/LegacyRuntimeBridge.tsx`：渲染兼容 DOM，加载脚本并显示运行时错误。
- `src/features/experience/legacy-runtime.ts`：一次性注入 `app.js`，避免重复初始化。
- `public/wp-content/themes/davidwhyte/app.js`：旧 Canvas/WebGL、视频纹理、音频和全屏景观状态。
- `src/content/experience.ts`：加载文案、控制文案和诗句。

## 约束

- 不在 React StrictMode 下加载旧脚本。
- 不直接改压缩脚本。
- Canvas 内部英文和资源切换仍由旧脚本控制，直到新引擎实现。
- 兼容组件只保留必要 DOM，不恢复 WordPress 页面外壳。
