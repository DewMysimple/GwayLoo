# 内容与页面快照

## 一句话结论

`index.html` 是当前页面结构、原始品牌文案、FAQ、导航、静态模块和部分运行时配置的集中快照，不等于完整的网站后端。

## 适用范围

涉及品牌名、诗句、标题、FAQ、按钮、导航、社交链接、静态账户/商城模块和页面路由的任务。

## 详细内容

- 页面包含原始 David Whyte 品牌、诗句、课程/图书馆/账户/商城等静态内容。
- `.xp-text-w`、`.xp-text-w-inside` 和 `.xp-text` 是体验场景文字的主要编辑位置。
- FAQ 使用 `.internal-module.faq` 及其 question/answer 结构。
- 页面保留多个原站相对路径，但当前仓库不是完整的多页面导出。
- 二次创作应先建立内容数据结构，再减少直接编辑大型 HTML 快照。

## 常见问题或陷阱

- 全局替换品牌字符串可能误伤来源说明、外链和兼容逻辑。
- 静态页面中的 WooCommerce、账户和表单标记不代表对应服务已经存在。
- 新增文案时要同时检查桌面/移动布局、字体加载和 WebGL 场景文字纹理。
