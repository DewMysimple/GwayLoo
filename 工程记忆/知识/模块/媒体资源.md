# 媒体资源

## 一句话结论

体验依赖一组强耦合的模型、纹理、字体、LUT、视频和音频资源；资源替换必须同时考虑路径、命名、格式和运行时加载关系。

## 适用范围

涉及美术图层、场景视频、音频、字体、模型、纹理、调色和 MSDF 文字资源的新增或替换。

## 详细内容

| 资源 | 路径 | 作用 |
| --- | --- | --- |
| 视频 | `resources/assets/xp/videos/` | 场景的 desktop/mobile、base/over 动态图层 |
| 音频 | `resources/assets/xp/sounds/` | 主循环、诗句/绘画循环和 CTA 反馈 |
| 纹理 | `resources/assets/xp/textures/` | 纸张、草地、噪声、图集和压缩纹理 |
| 模型 | `resources/assets/xp/models/scene.glb` | 3D 水彩场景模型 |
| 转码器 | `resources/assets/xp/libs/basis/` | KTX2/Basis 纹理读取 |
| 调色 | `resources/assets/xp/lut/` | `ink`、`dry` 等 LUT |
| 字体 | `resources/assets/fonts/` | CanelaText、Roobert 和图标字体 |
| MSDF | `resources/assets/xp/msdf/` | 场景文字纹理 |

## 常见问题或陷阱

- 视频替换必须保留相同的 desktop/mobile、base/over 和 1–6 约定，直到配置映射完成。
- 纹理和模型格式不能仅按文件扩展名判断，必须通过实际 HTTP 运行验证。
- 原始字体、音频、模型和视频不默认具有公开发布授权。
