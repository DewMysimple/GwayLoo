# 二次创作迁移

## 当前阶段

React 页面、中文控制文案、主题令牌和场景资源清单已抽离。旧 WebGL 引擎仍作为兼容层存在。

## 后续顺序

1. 用原创资源替换六组视频、音频、模型、纹理和字体，并记录来源。
2. 用 `sceneManifest` 驱动新的可维护场景加载器。
3. 将画布内英文标题和 CTA 转为配置内容。
4. 以 Three.js 或 React Three Fiber 逐步替换 `LegacyRuntimeBridge` 内的旧引擎。
5. 根据内容规模决定是否增加路由或 CMS。

## 原则

每一步都必须保留可验证的桌面和移动体验，不能把原始素材直接当作可公开品牌资产。
