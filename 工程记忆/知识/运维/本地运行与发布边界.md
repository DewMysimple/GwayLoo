# 本地运行与发布边界

## 一句话结论

当前工程支持本地静态实验，不代表已经满足公开部署、商用授权或完整网站功能要求。

## 适用范围

适用于本地启动、备份、公开发布准备和原始素材清理。

## 详细内容

- 本地运行：在项目根目录执行 `python -m http.server 8787`。
- 资源验证：通过浏览器 Network 面板检查模型、纹理、视频、音频、字体和脚本。
- 备份：修改前保留 Git 提交，重大迁移单独建立决策和日志。
- 发布前审查：替换原始品牌与文案，确认图片、视频、音频、字体、模型、代码和外链的使用边界。
- 功能边界：账户、商城、支付、表单和后台接口当前只保留静态快照，不应对外宣称可用。

## 常见问题或陷阱

- 本地有文件不代表这些文件已经被 Git 跟踪或会出现在远程克隆中。
- 页面入口可访问不代表引用的子页面、favicon 或支付样式完整。
- 公开发布前不能只做视觉检查，必须做资源来源和品牌字符串检查。
