# 体验运行时

## 一句话结论

`wp-content/themes/davidwhyte/app.js` 是当前体验核心，负责 Canvas/WebGL 初始化、场景交互、视频纹理、音频和部分第三方运行时协作。

## 适用范围

涉及主体验入口、场景切换、Canvas、隐藏 video/audio 元素、模型、纹理、LUT 或移动端适配的任务。

## 详细内容

- HTML 提供 `.xp-canvas`、成对隐藏 video 元素和多个 audio 元素。
- 视频资源按 desktop/mobile、base/over 和场景编号 1–6 组织，由运行时按场景按需加载。
- KTX2/Basis 转码器、模型、纹理、LUT 和 MSDF 文字纹理位于 `resources/assets/xp/`。
- `app.js` 为压缩产物，当前没有可直接维护的源模块边界。
- 运行验证应通过 HTTP 服务，不能只依赖 `file://`。

## 常见问题或陷阱

- 只替换视频但破坏 base/over 配对，可能造成场景层叠或交互反馈异常。
- 只验证桌面资源而忽略 mobile 目录，会导致移动端体验缺图或加载失败。
- 在未建立替代方案前直接改压缩脚本，难以定位 WebGL 初始化回归。
