# 本地开发与验证

## 一句话结论

当前工程应通过本地 HTTP 服务运行和验证，入口页与体验资源需要分别做静态路径和交互 smoke test。

## 适用范围

适用于 HTML、CSS、资源替换、场景交互和记忆系统变更后的本地检查。

## 详细内容

1. 在项目根目录启动 `python -m http.server 8787`。
2. 打开 `http://127.0.0.1:8787/index.html`。
3. 检查入口页 HTML、CSS、字体和主要脚本没有 404。
4. 检查 Canvas 初始化、场景切换、视频 base/over 和音频控制。
5. 至少分别检查桌面端和移动端资源路径。
6. 记忆变更后运行 `python 工具/memory_lint.py check`。

## 常见问题或陷阱

- 直接双击 HTML 会隐藏 HTTP、CORS、纹理转码和资源路径问题。
- 不应因为入口页返回 200 就认定所有相对页面和商城/账户功能可用。
- 端口被占用时可更换端口，但记录实际访问地址。
