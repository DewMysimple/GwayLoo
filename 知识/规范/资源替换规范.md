# 资源替换规范

## 一句话结论

在配置化映射完成前，资源替换必须遵守现有目录、文件名、尺寸方向和图层配对约定。

## 适用范围

适用于视频、音频、纹理、字体、模型、LUT 和 MSDF 文字资源的替换。

## 详细内容

- 视频必须分别提供 `desktop` 和 `mobile` 版本，除非任务明确取消设备差异。
- 每个场景保持 `base` 与 `over` 配对，并保留编号 `1` 至 `6`。
- 替换媒体时优先保持原扩展名和可被当前运行时读取的格式。
- 新增资源要记录用途、尺寸/格式、来源和是否为原创。
- 文案或视觉资源替换后必须检查加载顺序、可读性、对比度和移动端布局。
- 迁移到资源清单后，清单成为资源路径的主要事实来源；旧目录仅作为兼容层。

## 常见问题或陷阱

- 只替换 desktop 资源会让移动端继续显示旧素材或加载失败。
- 仅凭文件名相同不能证明视频编码、纹理压缩格式或音频可用。
- 不能把原始站点资源复制到新的公开品牌中而不记录来源。
